Constraint Satisfaction Problems (CSP)

Classes 11 & 12

What is a CSP?

In standard search problems, the state is a "black box" (an arbitrary data structure), and the goal test can be any function. CSPs are a specialized subset of search problems for identification problems:

  • The state is defined by variables \( X_i \) with values from a domain \( D \).
  • The goal test is a set of constraints specifying allowable combinations of values for subsets of variables.
  • Solutions are complete assignments satisfying all constraints.

Varieties of Constraints

  • Unary constraints: Involve a single variable (equivalent to reducing domains).
  • Binary constraints: Involve pairs of variables.
  • Higher-order constraints: Involve 3 or more variables (e.g., cryptarithmetic).
  • Preferences (soft constraints): Often representable by a cost for each variable assignment, leading to constrained optimization problems.

Constraint Graphs

A binary CSP can be represented as a Constraint Graph, where nodes are variables and arcs show constraints. General-purpose CSP algorithms use this graph structure to speed up search (e.g., identifying independent subproblems).

Solving CSPs: Backtracking Search

The standard search formulation of CSPs uses partial assignments:

  • Initial state: The empty assignment, \( \{\} \).
  • Successor function: Assign a value to an unassigned variable.
  • Goal test: The current assignment is complete and satisfies all constraints.

Backtracking search is depth-first search with two improvements:

  1. One variable at a time: Variable assignments are commutative, so we can fix the ordering. We only consider assignments to a single variable at each step.
  2. Check constraints as you go: Consider only values which do not conflict with previous assignments ("Incremental goal test" or fail-on-violation).

Improving Backtracking

General-purpose ideas can give huge gains in speed for backtracking search.

1. Filtering: Detecting inevitable failure early

  • Forward checking: Keep track of domains for unassigned variables and cross off values that violate a constraint when added to the existing assignment.
  • Constraint propagation: Forward checking doesn't provide early detection for all failures. Constraint propagation reasons from constraint to constraint to find tighter restrictions on variable domains.

2. Ordering: Which variable and which value?

  • Variable Ordering - Minimum Remaining Values (MRV): Choose the variable with the fewest legal values left in its domain. Also called the "most constrained variable" or "fail-fast" ordering.
  • Value Ordering - Least Constraining Value: Given a choice of variable, choose the value that rules out the fewest values in the remaining variables. This helps find a solution faster if one exists.

Combining these filtering and ordering ideas makes solving extremely large CSPs (e.g., 1000-queens) feasible!
