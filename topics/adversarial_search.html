Adversarial Search

Classes 9 & 10

Multiagent Environments & Game Theory

In multiagent environments, each agent needs to consider the actions of other agents and how they affect its own welfare. The unpredictability of these other agents introduces contingencies.

  • Competitive environments: The agents' goals are in conflict, giving rise to adversarial search problems—often known as games.
  • Co-operative environments: e.g., an automated taxi driver interacting with others safely.

Game Theory in AI

In AI, the most common games are deterministic, turn-taking, two-player, zero-sum games of perfect information (e.g., chess).

  • Zero-sum: A situation in which one person's gain is equivalent to another's loss, so the net change in wealth or benefit is zero. It is this opposition between the agents' utility functions that makes the situation adversarial.

Games and Game Trees

We consider games with two players: MAX and MIN. MAX moves first. A game can be formally defined with:

  • \(S_0\): Initial state.
  • PLAYER(s): Defines which player has the move in a state.
  • ACTIONS(s): Returns the set of legal moves.
  • RESULT(s, a): The transition model.
  • TERMINAL-TEST(s): True when the game is over.
  • UTILITY(s, p): A utility function (or objective/payoff function) defining the final numeric value for a game ending in terminal state \(s\) for player \(p\).

The initial state, ACTIONS function, and RESULT function define the game tree, where nodes are game states and edges are moves.

The Minimax Algorithm

Given a game tree, the optimal strategy can be determined from the minimax value of each node, \( \text{MINIMAX}(n) \).

  • The minimax value of a node is the utility (for MAX) of being in the corresponding state, assuming both players play optimally from there to the end.
  • MAX prefers to move to a state of maximum value, whereas MIN prefers a state of minimum value.

Minimax performs a complete depth-first exploration of the game tree.

  • Time complexity: \( O(b^m) \)
  • Space complexity: \( O(bm) \) or \( O(m) \)

For real games, this time cost is totally impractical. We need algorithms that can make good decisions within resource limits.

Resource Limits & Depth-Limited Search

In realistic games, we cannot search to the leaves! Solution: Search only to a limited depth in the tree, and replace terminal utilities with an evaluation function for non-terminal positions.

Game Tree Pruning: Alpha-Beta Pruning

The problem with minimax search is that the number of game states it examines is exponential in depth. We can't eliminate the exponent, but we can effectively cut it in half using pruning.

Alpha-Beta Pruning returns the exact same move as minimax would, but it prunes away branches that cannot possibly influence the final decision.

  • \( \alpha \) = the value of the best (i.e., highest-value) choice we have found so far at any choice point along the path for MAX.
  • \( \beta \) = the value of the best (i.e., lowest-value) choice we have found so far at any choice point along the path for MIN.

If we find a node whose value is worse than \( \alpha \) (for MAX) or worse than \( \beta \) (for MIN), we can stop evaluating its children.
