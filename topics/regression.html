Regression

Linear regression & logistic regression — lecture notes by Dr. Ohidujjaman Tuhin, CSE, UIU

Two kinds of regression

Both methods fit a model to labelled training data, so both are supervised learning. They differ in what they predict:

Linear regressionLogistic regression
PredictsA continuous number (e.g. sales)A probability between 0 and 1, then a class
Model\(y = a_0 + a_1 x\)\(p = \dfrac{1}{1 + e^{-z}}\),   \(z = \log(\text{odds})\) linear in \(x\)
Used forRegression / forecastingClassification (pass / fail)

Despite the name, logistic regression is a classifier. It regresses the log-odds on the input, then turns that into a probability and thresholds it.

Linear Regression

The linear regression equation is

\[ y = a_0 + a_1 x + e \]

where \(a_1\) is the slope, \(a_0\) the intercept, and \(e\) the error term the fitted line does not capture. The coefficients come from the data:

\[ a_1 = \frac{\overline{xy} - \bar{x}\,\bar{y}}{\overline{x^2} - \bar{x}^2} \qquad\qquad a_0 = \bar{y} - a_1 \bar{x} \]

A bar means "average over the data". So \(\overline{xy}\) is the mean of the products \(x_i y_i\), and \(\overline{x^2}\) is the mean of the squares — not the square of the mean, which is \(\bar{x}^2\). Mixing those two up is the most common slip.

These are the least-squares coefficients: the line that minimises the sum of squared vertical errors. The same slope is often written in this form instead — the two are algebraically identical:

\[ a_1 = \frac{\sum (x_i-\bar{x})(y_i-\bar{y})}{\sum (x_i-\bar{x})^2} \]

Average\(\bar{x} = 3\)\(\bar{y} = 2.52\)\(\overline{x^2} = 11\)\(\overline{xy} = 8.88\)
\[ a_1 = \frac{8.88 - 3 \times 2.52}{11 - 3^2} = \frac{8.88 - 7.56}{2} = \frac{1.32}{2} = \mathbf{0.66} \] \[ a_0 = 2.52 - 0.66 \times 3 = 2.52 - 1.98 = \mathbf{0.54} \]

So the regression equation is

\[ y = 0.54 + 0.66\,x \]

Checking your line. A least-squares line with an intercept always passes through \((\bar{x}, \bar{y})\): here \(0.54 + 0.66 \times 3 = 2.52 = \bar{y}\). ✓ It is a ten-second check that catches most arithmetic errors in \(a_0\).

Also notice both predictions extrapolate beyond the observed weeks 1–5. The line fits the data closely, but week 12 is more than twice as far out as the data reaches — the further you extrapolate, the less the model can be trusted.

Logistic Regression

Logistic regression uses the sigmoid function to squash any real number into the range (0, 1), so it can be read as a probability:

\[ s(x) = \frac{1}{1 + e^{-x}} \]

The sigmoid is an S-shaped curve: very negative inputs give values near 0, very positive inputs give values near 1, and an input of 0 gives exactly 0.5 — the usual threshold between the two classes.

The model is linear in the log-odds, and the probability comes from passing that through the sigmoid:

\[ z = \log(\text{odds}) = \log\frac{p}{1-p} \qquad\qquad p = \frac{1}{1 + e^{-z}} \]

Here \(\log\) is the natural logarithm. The two equations are inverses of each other, and both directions come up in exams.

Worked example: pass or fail

The pass/fail record of five students:

Hours studied2915332839
Pass (1) / Fail (0)00111

Assume the optimizer suggests this model for the odds of passing:

\[ \log(\text{odds}) = z = -64 + 2 \times \text{hours} \]

Problem 1 — probability of passing after 33 hours

\[ z = -64 + 2 \times 33 = -64 + 66 = 2 \] \[ p = \frac{1}{1 + e^{-2}} = \frac{1}{1 + 0.1353} \approx \mathbf{0.88} \]

A student who studies 33 hours has about an 88% chance of passing.

Problem 2 — minimum hours for more than 95% probability

Set \(p = 0.95\) and solve for \(z\), then for hours:

\[ \frac{1}{1 + e^{-z}} = 0.95 \;\Rightarrow\; 0.95\,(1 + e^{-z}) = 1 \;\Rightarrow\; 0.95\,e^{-z} = 0.05 \] \[ e^{-z} = \frac{0.05}{0.95} = 0.0526 \;\Rightarrow\; -z = \ln(0.0526) = -2.94 \;\Rightarrow\; z = 2.94 \] \[ 2.94 = -64 + 2 \times \text{hours} \;\Rightarrow\; \text{hours} = \frac{66.94}{2} = \mathbf{33.47} \]

The student should study at least 33.47 hours to pass with more than 95% probability.

Shortcut. Solving for \(z\) is just the log-odds formula run backwards — one line instead of four, and a good way to check the long derivation:

\[ z = \ln\frac{p}{1-p} = \ln\frac{0.95}{0.05} = \ln 19 \approx 2.944 \]

How well does the given model fit the data?

The decision threshold \(p = 0.5\) is where \(z = 0\), i.e. \(-64 + 2 \times \text{hours} = 0\), so hours = 32. Run the five students through it:

Hours\(z\)\(p\)PredictedActual
15−34≈ 0.000FailFail✓
28−8≈ 0.000FailPass✗
29−6≈ 0.002FailFail✓

Four of five are correct; the 28-hour student is misclassified. That is not a flaw in this particular model — no model based only on hours can get all five right, because the 28-hour student passed while the 29-hour student failed. Any rule that says "more hours, more likely to pass" must get at least one of those two wrong. Real data is rarely perfectly separable, which is exactly why logistic regression outputs a probability rather than a hard yes/no.

Exam Checklist

  • For linear regression, build the table with \(x^2\) and \(xy\) columns, then sum and average every column before touching the formula.
  • Keep \(\overline{x^2}\) (mean of squares) and \(\bar{x}^2\) (square of the mean) apart.
  • Compute \(a_1\) first — \(a_0\) depends on it. Then check the line passes through \((\bar{x}, \bar{y})\).
  • Write the final equation explicitly, then substitute for each prediction.
  • For logistic regression, compute \(z\) first, then \(p = 1/(1+e^{-z})\).
  • To find the input needed for a target probability, use \(z = \ln\frac{p}{1-p}\), then solve the linear equation for the input.
  • \(p = 0.5\) exactly when \(z = 0\) — that gives the decision boundary.
