Every pair of regions that share a border must get different colours. Tasmania borders nothing, so it can take any colour — it is the independent subproblem from the notes.

How to Read It

  • The search assigns one variable at a time. The region currently being worked on is outlined in white, and the Domains panel on the right shows which colours each region still has available.
  • Backtracking is just depth-first search with fail-on-violation: before committing a colour it checks the already-assigned neighbours, and a clash flashes red and is skipped rather than explored.
  • When a region runs out of colours the search backtracks — it undoes the last assignment and tries the next colour there instead.

What each improvement does

ToggleWhat changes on screen
Forward checking The moment a colour is assigned, that colour is struck out of every unassigned neighbour's domain. When some domain empties, the failure is caught immediately — the region flashes with a dashed red outline — instead of being discovered many assignments later.
MRV Changes which region is picked next: the one with the fewest legal colours left — the most constrained variable, so failure is discovered early rather than after a long wasted branch. On the 2-colour run it alone cuts backtracks from 10 to 4.
LCV Changes which colour is tried first at a region: the one that rules out the fewest options for the neighbours, keeping as many downstream choices open as possible.

Things worth trying

  • Set colours to 2 and run it. This is the interesting case. Australia cannot be 2-coloured, so the search has to exhaust every possibility before it can report failure — and that is where the improvements earn their keep:

  • Be aware that 3 colours is too easy to show much. With three colours plain backtracking solves Australia in 7 assignments and never backtracks at all, so the heuristics have nothing to repair — forward checking only trims consistency checks from 11 to 7. That is not a flaw in the heuristics; it is what an easy instance looks like. The reason is structural: SA's five neighbours form an open chain rather than a closed ring, so they only ever need two colours between them and a third is always left over for SA.
  • Watch Tasmania. It has no constraints at all, so whatever it is given first is never revisited — the independent-subproblem idea from the CSP notes, visible in the trace.
