Every pair of regions that share a border must get different colours. Tasmania borders nothing, so it can take any colour — it is the independent subproblem from the notes.

How to Read It

  • The search assigns one variable at a time. The region currently being worked on is outlined in white, and the Domains panel on the right shows which colours each region still has available.
  • Backtracking is just depth-first search with fail-on-violation: before committing a colour it checks the already-assigned neighbours, and a clash flashes red and is skipped rather than explored.
  • When a region runs out of colours the search backtracks — it undoes the last assignment and tries the next colour there instead.

What each improvement does

ToggleWhat changes on screen
Forward checking The moment a colour is assigned, that colour is struck out of every unassigned neighbour's domain. When some domain empties, the failure is caught immediately — the region flashes with a dashed red outline — instead of being discovered many assignments later.
MRV Changes which region is picked next: the one with the fewest legal colours left — the most constrained variable, so failure is discovered early rather than after a long wasted branch. On the 2-colour run it alone cuts backtracks from 10 to 4.
LCV Changes which colour is tried first at a region: the one that rules out the fewest options for the neighbours, keeping as many downstream choices open as possible.

Things worth trying

  • Set colours to 2 and run it. This is the interesting case. Australia cannot be 2-coloured, so the search has to exhaust every possibility before it can report failure — and that is where the improvements earn their keep:

  • Be aware that 3 colours is too easy to show much. With three colours plain backtracking solves Australia in 7 assignments and never backtracks at all, so the heuristics have nothing to repair — forward checking only trims consistency checks from 11 to 7. That is not a flaw in the heuristics; it is what an easy instance looks like. The reason is structural: SA's five neighbours form an open chain rather than a closed ring, so they only ever need two colours between them and a third is always left over for SA.
  • Watch Tasmania. It has no constraints at all, so whatever it is given first is never revisited — the independent-subproblem idea from the CSP notes, visible in the trace.

Tracing It on Paper

An exam will ask you to do this by hand rather than watch it run. Below is the complete search tree for the case the simulation runs — 2 colours, plain backtracking, no improvements — so you can see exactly what a full answer looks like.

How to draw it quickly

Two features of this tree make it far less work than it looks:

  1. It is a spine, not a bush. With only two colours at most one value survives at each level, so the tree is essentially a vertical line with small rejected stubs hanging off it.
  2. The path from the root is the assignment. You never need to rewrite the partial assignment at each node — just read down the spine.

Then three things earn the marks:

  • Label every rejection with the variable it clashed with — SA=R ✗ WA, not a bare cross. That is your evidence you actually performed the consistency check.
  • Mark the dead end and say where you backtrack to. The dead end is the variable that ran out of values (SA here), not the one it clashed with.
  • State the conclusion: the search space is exhausted, so no 2-colouring exists.

Checking your own answer

Three numbers fall out of a correct tree, and they are worth quoting:

QuantityValueHow to read it off the tree
Consistency checks22Total number of boxes — every box is one value tested.
Assignments10Number of solid teal boxes.
Backtracks10Equal to assignments here, because every assignment is eventually undone.

There is a useful internal check too: the WA=R and WA=G halves cost exactly the same — 11 boxes, 5 assignments and 5 backtracks each. If your halves do not match, you have slipped somewhere.

Careful with that symmetry. The two halves contain the same nodes with R and G swapped, but they are not left-to-right mirror images. The value order stays R-then-G in both halves, so the rejected sibling is tried first on the left (node 2) and second on the right (node 22). You can safely write "by symmetry the WA=G branch costs the same and also fails" — but do not copy the left drawing flipped.

The one-line justification worth adding

WA, NT and SA form a triangle — WA–NT, NT–SA and SA–WA are all constraints — and a triangle needs three colours. So no 2-colouring exists, before you trace anything. Lead with that, then give the tree as the mechanical demonstration: it shows you understand why the search must fail, not merely that it did.

Notice how late the contradiction surfaces. SA is assigned sixth under this ordering, so the search commits five variables before discovering the problem — and then does it all again on the other half. That waste is exactly what MRV removes, by picking SA early instead.
