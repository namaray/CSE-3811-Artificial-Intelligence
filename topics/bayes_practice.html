Question 1 — Rain, Traffic and Lateness

You model your morning commute with three Boolean random variables:

  • \(R\): it rains  •  \(T\): there is traffic  •  \(L\): you are late

Rain causes traffic, and traffic causes lateness. Rain has no other route to making you late. Your model:

\[ P(+r) = 0.2 \] \[ P(+t \mid +r) = 0.8 \qquad P(+t \mid -r) = 0.1 \] \[ P(+l \mid +t) = 0.6 \qquad P(+l \mid -t) = 0.1 \]

(a) State the domain of each variable. How many rows does the full joint \(P(R,T,L)\) have? In general, how many for \(n\) variables of domain size \(d\)?

Answer

Each variable is Boolean, with domain \(\{+x, -x\}\) (i.e. {true, false}), so \(d = 2\).

The full joint has \(2^3 = \mathbf{8}\) rows — one per complete assignment. In general a joint over \(n\) variables of domain size \(d\) has \(\mathbf{d^n}\) rows, which is why writing out a full joint is impractical for all but the smallest problems.

(b) Draw the Bayes' net implied by the description, and write the factorization it encodes.

Answer

A chain: \(R \rightarrow T \rightarrow L\). Three nodes, two arcs, no arc from \(R\) to \(L\) — because rain affects lateness only through traffic.

\[ P(R, T, L) = P(R)\, P(T \mid R)\, P(L \mid T) \]

Each node contributes one factor: its own distribution conditioned on its parents. \(R\) has no parents, \(T\) has parent \(R\), \(L\) has parent \(T\).

(c) Compute the full joint distribution. Check that it sums to 1.

Answer

Multiply the three local factors for each of the 8 assignments, e.g. \(P(+r,+t,+l) = 0.2 \times 0.8 \times 0.6 = 0.096\).

(d) Marginalize to find \(P(+t)\) and \(P(+l)\).

Answer

Sum out the variables you don't care about.

\[ P(+t) = 0.096 + 0.064 + 0.048 + 0.032 = \mathbf{0.24} \] \[ P(+l) = 0.096 + 0.004 + 0.048 + 0.072 = \mathbf{0.22} \]

Faster check without the full joint, conditioning on the parent:

\[ P(+t) = P(+t \mid +r)P(+r) + P(+t \mid -r)P(-r) = 0.8(0.2) + 0.1(0.8) = 0.24 \] \[ P(+l) = P(+l \mid +t)P(+t) + P(+l \mid -t)P(-t) = 0.6(0.24) + 0.1(0.76) = 0.22 \]

(e) Compute \(P(+r \mid +t)\).

Answer

Definition of conditional probability — joint over marginal:

\[ P(+r \mid +t) = \frac{P(+r, +t)}{P(+t)} = \frac{0.096 + 0.064}{0.24} = \frac{0.16}{0.24} = \frac{2}{3} \approx \mathbf{0.667} \]

Traffic is evidence for rain: the prior \(P(+r) = 0.2\) rises to \(0.667\).

(f) You arrive late. Use Bayes' rule to find \(P(+r \mid +l)\).

Answer

This is the diagnostic direction — the model is stated causally, so Bayes' rule reverses it.

\[ P(+r \mid +l) = \frac{P(+l \mid +r)P(+r)}{P(+l)} \]

First \(P(+l \mid +r)\), by summing over traffic:

\[ P(+l \mid +r) = P(+l \mid +t)P(+t \mid +r) + P(+l \mid -t)P(-t \mid +r) = 0.6(0.8) + 0.1(0.2) = 0.5 \] \[ P(+r \mid +l) = \frac{0.5 \times 0.2}{0.22} = \frac{0.10}{0.22} = \frac{5}{11} \approx \mathbf{0.455} \]

Equivalently, straight off the joint: \(P(+r,+l) = 0.096 + 0.004 = 0.10\), divided by \(P(+l) = 0.22\).

Being late more than doubles your belief in rain (0.2 → 0.455) but leaves it below even, because most lateness comes from the much more likely no-rain world.

(g) Are \(R\) and \(L\) independent? Show the test.

Answer

Test whether \(P(+l \mid +r) = P(+l)\):

\[ P(+l \mid +r) = 0.5 \qquad P(+l) = 0.22 \qquad 0.5 \neq 0.22 \]

Not independent. Equivalently \(P(+r,+l) = 0.10\) but \(P(+r)P(+l) = 0.2 \times 0.22 = 0.044\).

This is what we expect: rain makes traffic more likely, and traffic makes lateness more likely, so rain does carry information about lateness — just indirectly.

(h) Are \(L\) and \(R\) conditionally independent given \(T\)? Show the test, and say what it means.

Answer

Test whether \(P(L \mid T, R) = P(L \mid T)\) for every combination:

\[ P(+l \mid +t, +r) = \frac{0.096}{0.096+0.064} = \frac{0.096}{0.16} = 0.6 \] \[ P(+l \mid +t, -r) = \frac{0.048}{0.048+0.032} = \frac{0.048}{0.08} = 0.6 \] \[ P(+l \mid +t) = \frac{0.096+0.048}{0.24} = \frac{0.144}{0.24} = 0.6 \]

All equal, so \(L \perp\!\!\!\perp R \mid T\). (The same holds for \(-t\): all three work out to 0.1.)

Meaning: once you already know whether there is traffic, learning about rain tells you nothing more about being late. Rain's entire influence on \(L\) is routed through \(T\) — which is exactly what the missing \(R \rightarrow L\) arc asserts.

Note the contrast with (g): \(R\) and \(L\) are dependent, yet conditionally independent given \(T\). Independence and conditional independence are different properties; neither implies the other.

(j) Why is multiplying the local conditionals guaranteed to give a proper joint distribution?

Answer

Start from the chain rule, which is valid for every distribution — no assumptions:

\[ P(R,T,L) = P(R)\,P(T \mid R)\,P(L \mid R, T) \]

The net then asserts one conditional independence, \(L \perp\!\!\!\perp R \mid T\), which lets us shrink the last factor:

\[ P(L \mid R, T) = P(L \mid T) \quad\Longrightarrow\quad P(R,T,L) = P(R)\,P(T \mid R)\,P(L \mid T) \]

So the product form is the chain rule plus the independences the topology encodes. Note the consequence: not every joint can be represented by a given net — the topology enforces independences, and a distribution that violates them cannot be written in that factored form.

Question 2 — Joint tables, events and independence

Two joint distributions over Boolean \(A\) and \(B\):

(+a, +b)(+a, −b)(−a, +b)(−a, −b)
Table 10.120.280.180.42
Table 20.200.200.100.50

(a) Verify each is a valid distribution, and compute the marginals \(P(A)\) and \(P(B)\) for both.

Answer

Both sum to 1.00, and every entry is \(\geq 0\) — valid.

\[ \textbf{Table 1: } P(+a) = 0.12+0.28 = 0.40 \qquad P(+b) = 0.12+0.18 = 0.30 \] \[ \textbf{Table 2: } P(+a) = 0.20+0.20 = 0.40 \qquad P(+b) = 0.20+0.10 = 0.30 \]

So \(P(-a) = 0.60\) and \(P(-b) = 0.70\) in both cases.

Worth noticing: the two tables have identical marginals but different joints. Marginals do not determine the joint — you cannot reconstruct a joint from its marginals unless you additionally assume independence.

(b) Using Table 2, compute \(P(+a \text{ OR } +b)\).

Answer

Inclusion–exclusion — add the two events, then subtract the overlap you counted twice:

\[ P(+a \cup +b) = P(+a) + P(+b) - P(+a, +b) = 0.40 + 0.30 - 0.20 = \mathbf{0.50} \]

Or just sum the matching rows directly: \(0.20 + 0.20 + 0.10 = 0.50\) ✓

(c) Using Table 2, compute \(P(+a \mid +b)\).

Answer
\[ P(+a \mid +b) = \frac{P(+a, +b)}{P(+b)} = \frac{0.20}{0.30} = \frac{2}{3} \approx \mathbf{0.667} \]

(d) Which table has \(A\) and \(B\) independent? Show the test for both.

Answer

Independence requires \(P(a,b) = P(a)P(b)\) for every cell, not just one.

Cell\(P(a)P(b)\)Table 1Table 2
(+a, +b)0.40 × 0.30 = 0.120.12 ✓0.20 ✗

Question 3 — Bayes' net structure and semantics

The alarm network has five Boolean variables: \(B\) burglary, \(E\) earthquake, \(A\) alarm, \(J\) John calls, \(M\) Mary calls. A burglary or an earthquake can set off the alarm; John and Mary each call when they hear it.

(a) Give the network structure and the joint factorization it encodes.

Answer

Arcs: \(B \rightarrow A\), \(E \rightarrow A\), \(A \rightarrow J\), \(A \rightarrow M\).

\[ P(B,E,A,J,M) = P(B)\,P(E)\,P(A \mid B, E)\,P(J \mid A)\,P(M \mid A) \]

\(B\) and \(E\) have no parents, \(A\) has two, and \(J\) and \(M\) have one each. The structure asserts that John and Mary call based only on the alarm — neither hears the burglar directly, and given the alarm, their calls are independent of each other.

(b) How many free parameters does this net need, versus the full joint?

Answer

A node with \(k\) Boolean parents needs \(2^k\) free numbers.

The full joint would need \(2^5 - 1 = \mathbf{31}\). Ten numbers instead of thirty-one, and the gap widens sharply as variables are added.

(c) Using \(P(+b)=0.001\), \(P(+e)=0.002\), \(P(+a \mid +b,-e)=0.94\), \(P(+j \mid +a)=0.90\), \(P(+m \mid +a)=0.70\), compute \(P(+b, -e, +a, +j, -m)\).

Answer

Read one number out of each CPT and multiply — that is all "probabilities in BNs" means for a full assignment.

\[ P(+b,-e,+a,+j,-m) = P(+b)\,P(-e)\,P(+a \mid +b,-e)\,P(+j \mid +a)\,P(-m \mid +a) \] \[ = 0.001 \times 0.998 \times 0.94 \times 0.90 \times 0.30 \approx \mathbf{0.000253} \]

Watch the two complements: \(P(-e) = 1 - 0.002 = 0.998\) and \(P(-m \mid +a) = 1 - 0.70 = 0.30\). Forgetting to flip these is the most common error on this type of question.

(d) You model \(n\) independent coin flips as a Bayes' net. What does it look like, and how many parameters does it need?

Answer

No arcs at all — \(n\) isolated nodes \(X_1, \dots, X_n\), each with its own distribution.

\[ P(X_1, \dots, X_n) = \prod_{i=1}^{n} P(X_i) \]

That needs \(\mathbf{n}\) parameters (one per coin), against \(2^n - 1\) for the full joint. An arc-free net can represent only those distributions whose variables are absolutely independent — which is exactly the assumption being made here.

Question 4 — Short answers

(a) In probabilistic reasoning, what are the observed variables, the unobserved variables, and the model?

Answer
  • Observed variables (evidence): what the agent knows about the state of the world — sensor readings, symptoms.
  • Unobserved variables: what it must reason about — where an object is, which disease is present.
  • Model: knowledge of how the known variables relate to the unknown ones.

Probabilistic reasoning is then the framework for managing beliefs given that evidence.

(b) Give two differences between a probabilistic model and a constraint satisfaction problem.

Answer
  • A CSP's table says whether an assignment is possible (true/false); a probabilistic model's joint says how likely it is (a number in [0,1]).
  • A probability distribution must be normalized — sum to 1.0. A constraint has no such requirement.

The structures are otherwise deliberately parallel: variables with domains, assignments called outcomes, and the hope that only certain variables interact directly.

(c) Why is Bayes' rule useful? Answer in one sentence.

Answer

It lets you build one conditional from its reverse — which matters because one direction is often easy to obtain and the other is what you actually want, as with causal \(P(\text{effect} \mid \text{cause})\) versus diagnostic \(P(\text{cause} \mid \text{effect})\).

(d) What two things define a Bayes' net?

Answer

Topology plus local conditional probabilities. Precisely: a set of nodes (one per variable), a directed acyclic graph, and for each node a conditional distribution over that variable for every combination of its parents' values — its CPT.

(e) Can any joint distribution be represented by any Bayes' net? Explain.

Answer

No. The topology enforces conditional independences, so a given net can only represent distributions that actually satisfy them. A distribution in which \(L\) still depends on \(R\) after \(T\) is known cannot be written as \(P(R)P(T \mid R)P(L \mid T)\).

The fully-connected net is the exception — it asserts no independences and so can represent anything, but it also needs as many parameters as the full joint, which defeats the purpose.

(f) A friend claims their Bayes' net has no arcs but the variables are not independent. What is wrong?

Answer

The claim is contradictory. An arc-free net factors as \(P(X_1)P(X_2)\cdots P(X_n)\), which is precisely the definition of absolute independence, so it can only represent distributions whose variables are independent. If the variables are genuinely dependent, the net is the wrong model for them.
