Uninformed Search Strategies

Class 3

Search Problems

A search problem consists of:

  • A state space: The set of all possible states.
  • A successor function: Returns actions and costs.
  • A start state and a goal test.

A solution is a sequence of actions (a plan) which transforms the start state to a goal state.

Note: The world state includes every last detail of the environment. A search state keeps only the details needed for planning (abstraction).

State Space Graphs vs. Search Trees

  • State Space Graph: A mathematical representation of a search problem. Nodes are abstracted world configurations. Arcs represent successors (action results). In a state space graph, each state occurs only once!
  • Search Tree: A "what if" tree of plans and their outcomes. The start state is the root node. Children correspond to successors. Each node in the search tree is an entire path in the state space graph.

Search Algorithm Properties

We evaluate search algorithms based on the following properties:

  • Complete: Guaranteed to find a solution if one exists?
  • Optimal: Guaranteed to find the least cost path?
  • Time complexity: How long does it take?
  • Space complexity: How much memory is needed?

Let \( b \) be the branching factor and \( m \) be the maximum depth.

Number of nodes in entire tree = \( 1 + b + b^2 + \dots + b^m = O(b^m) \)

Uninformed Search Algorithms

1. Depth-First Search (DFS)

Strategy: expand a deepest node first. Implementation: Fringe is a LIFO stack.

  • Time Complexity: \( O(b^m) \) (Could process the whole tree).
  • Space Complexity: \( O(bm) \) (Only has siblings on path to root).
  • Complete? Only if we prevent cycles ( \( m \) must be finite).
  • Optimal? No, it finds the "leftmost" solution, regardless of depth or cost.

2. Breadth-First Search (BFS)

Strategy: expand the shallowest node first. Implementation: Fringe is a FIFO queue.

Let \( s \) be the depth of the shallowest solution.

  • Time Complexity: \( O(b^s) \)
  • Space Complexity: \( O(b^s) \) (Has roughly the last tier in the fringe).
  • Complete? Yes, if \( s \) is finite.
  • Optimal? Only if costs are all 1.

3. Depth Limited Search (DLS)

Strategy: Use DFS with a depth limit.

4. Iterative Deepening

Idea: Get DFS's space advantage with BFS's time/shallow-solution advantages.

  • Run a DFS with depth limit 1. If no solution...
  • Run a DFS with depth limit 2. If no solution...
  • Run a DFS with depth limit 3... and so on.

Isn't that wastefully redundant? Generally, most work happens in the lowest level searched, so it's not so bad!

5. Uniform Cost Search (UCS)

BFS finds the shortest path in terms of number of actions, but not the least-cost path. UCS finds the least-cost path.

Strategy: Expand the cheapest node first. Implementation: Fringe is a priority queue (priority = cumulative cost).

  • Time/Space Complexity: \( O(b^{C^*/\epsilon}) \) where \( C^* \) is the cost of the optimal solution and \( \epsilon \) is the minimum arc cost.
  • Complete? Yes, assuming best solution has a finite cost and minimum arc cost is positive.
  • Optimal? Yes!
  • Issues: UCS explores options in every "direction" and has no information about goal location.
