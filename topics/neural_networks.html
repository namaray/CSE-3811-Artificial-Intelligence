Neural Networks: Activation Functions & the Perceptron

Lecture notes by Dr. Ohidujjaman Tuhin, CSE, UIU

The Neuron

An artificial neuron takes inputs \(I_1, I_2, \dots\), multiplies each by a weight, adds them up (plus an optional bias \(b\)), and passes the total through an activation function \(\varphi\):

\[ v = I_1 w_1 + I_2 w_2 + \cdots + b \qquad\qquad y_k = \varphi(v) \]

\(v\) is called the induced local field. An activation function decides whether a neuron should be activated or not — that is, whether the neuron's input is important in the process of prediction — using simple mathematical operations.

The running example

Every function below is applied to the same neuron: inputs \(I_1 = 1,\ I_2 = 1\), weights \(w_1 = 0.5,\ w_2 = -0.3\), no bias.

\[ v = I_1 w_1 + I_2 w_2 = 1 \times 0.5 + 1 \times (-0.3) = 0.5 - 0.3 = 0.2 \]

Watch the sign of \(w_2\). Two of the hand-drawn diagrams label it \(w_2 = 0.3\), but every calculation in the notes uses \(-0.3\) and gets \(v = 0.2\). It matters: with \(+0.3\) you would get \(v = 0.8\), and the piecewise-linear answer would change from 0.7 to 1.

1. Threshold function

\[ \varphi(v) = \begin{cases} 1, & v \ge 0 \\ 0, & v < 0 \end{cases} \]

A hard on/off switch. Since \(0.2 \ge 0\), the output is \(y_k = \varphi(0.2) = \mathbf{1}\).

2. Piecewise-linear function

\[ \varphi(v) = \begin{cases} 1, & v \ge \tfrac{1}{2} \\[3pt] v + \tfrac{1}{2}, & -\tfrac{1}{2} < v < \tfrac{1}{2} \\[3pt] 0, & v \le -\tfrac{1}{2} \end{cases} \]

The middle piece is the straight line through \((-\tfrac12, 0)\) and \((\tfrac12, 1)\). Using the two-point form of a line:

\[ \frac{v - \tfrac12}{\tfrac12 + \tfrac12} = \frac{\varphi(v) - 1}{1 - 0} \;\Rightarrow\; v - \tfrac12 = \varphi(v) - 1 \;\Rightarrow\; \varphi(v) = v + \tfrac12 \]

Since \(-\tfrac12 < 0.2 < \tfrac12\), the middle piece applies: \(\varphi(0.2) = 0.2 + 0.5 = \mathbf{0.7}\).

3. Sigmoid (logistic) function

\[ \varphi(v) = \frac{1}{1 + e^{-av}} \]

where \(a\) is the slope parameter: as \(a\) increases the curve gets steeper, approaching the threshold function. Its key values:

\(v\)Working\(\varphi(v)\)
\(-\infty\)\(\frac{1}{1 + e^{\infty}} = \frac{1}{\infty}\)0
\(0\)\(\frac{1}{1 + e^{0}} = \frac{1}{1+1}\)1/2
\(+\infty\)\(\frac{1}{1 + e^{-\infty}} = \frac{1}{1+0}\)1

With \(a = 1\):

\[ \varphi(0.2) = \frac{1}{1 + e^{-0.2}} = \frac{1}{1 + \frac{1}{e^{0.2}}} \approx \mathbf{0.5498} \]

Unlike the first two, the sigmoid is smooth everywhere, which is what lets a network be trained by gradients — see the perceptron below.

4. Signum function (hyperbolic tangent)

\[ \varphi(v) = \tanh(v) \qquad\Rightarrow\qquad \tanh(0.2) \approx \mathbf{0.1974} \]

The hyperbolic tangent is the ratio of the hyperbolic sine to the hyperbolic cosine. Hyperbolic functions are analogues of the ordinary trigonometric functions, defined using the hyperbola rather than the circle. Its output ranges from −1 to +1, centred on 0.

A naming note. These notes label this the "signum function" but use the formula \(\tanh(v)\). Strictly, the signum (sign) function is a hard step to \(-1\) or \(+1\) — it would give \(\text{sgn}(0.2) = 1\) — and \(\tanh\) is its smooth version. In an exam, follow the notes and use \(\tanh\) when asked for this function, but know the distinction in case a question means the hard step.

Stochastic Model of a Neuron

Here a neuron may reside in only one of two states, \(+1\) or \(-1\), and the decision to fire — switch from off to on — is probabilistic: randomly determined, so it can be analysed statistically but not predicted precisely.

\[ x = \begin{cases} +1, & \text{with probability } P(v) \\ -1, & \text{with probability } 1 - P(v) \end{cases} \qquad\qquad P(v) = \frac{1}{1 + e^{-v/T}} \]
  • \(x\) is the state of the neuron, and \(P(v)\) the probability of firing.
  • \(v\) is the induced local field.
  • \(T\) is the pseudo-temperature, which controls the noise level and therefore the uncertainty in firing.
Temperature\(P(v)\) for \(v = 0.2\)Behaviour
\(T \rightarrow 0\)\(\frac{1}{1 + e^{-\infty}} = 1\)Deterministic (noiseless) — it always fires when \(v > 0\), and never when \(v < 0\): exactly the threshold function.
\(T = 10{,}000\)\(\frac{1}{1 + e^{-0.00002}} = \frac{1}{1.99998} \approx 0.500005\)Almost a coin flip.
\(T \rightarrow \infty\)\(\frac{1}{1 + e^{0}} = \frac{1}{2}\)Pure noise — fires half the time whatever the input.

At \(T = 10{,}000\) the probability of not firing is \(1 - 0.500005 = 0.499995\). The higher the temperature, the less the input matters.

The Perceptron

A perceptron is a simple model of a biological neuron used in artificial neural networks — a machine-based algorithm that learns how to classify data.

Training alternates two passes for each training pattern:

  1. Forward pass — compute \(v\) and the output \(f = \varphi(v)\).
  2. Backpropagation — compute the error term \(\delta\), then nudge every weight to reduce the error.
\[ \delta = f'(v)\,(d - f) = f(1 - f)\,(d - f) \qquad\qquad \Delta w_i = \eta\, I_i\, \delta \qquad\qquad \Delta b = \eta \cdot 1 \cdot \delta \]

where \(d\) is the desired output, \(\eta\) the learning rate, and \(f(1-f)\) the derivative of the sigmoid (with \(a = 1\)). The bias behaves like a weight on a constant input of 1.

Worked example

Question. A perceptron has initial weights \(w_1 = 0.5,\ w_2 = 0.3\) and bias \(b = 0.1\), uses the sigmoid activation with \(a = 1\), and learning rate \(\eta = 0.1\). Train it on the data below, then find the output for the test input \((0, 1)\).

\(I_1\)\(I_2\)Output \(d\)
111
000
01? — test

Pattern 1 — \((I_1 = 1,\ I_2 = 1,\ d = 1)\)

Forward pass:

\[ v = I_1 w_1 + I_2 w_2 + b = 1 \times 0.5 + 1 \times 0.3 + 0.1 = 0.9 \] \[ f = \frac{1}{1 + e^{-0.9}} = 0.711 \]

Backpropagation:

\[ \delta = f(1-f)(d-f) = 0.711\,(1 - 0.711)\,(1 - 0.711) = 0.05938 \] \[ \Delta w_1 = \eta\, I_1\, \delta = 0.1 \times 1 \times 0.05938 = 0.005938 \;\Rightarrow\; w_1 = 0.5 + 0.005938 = 0.5059 \] \[ \Delta w_2 = \eta\, I_2\, \delta = 0.1 \times 1 \times 0.05938 = 0.005938 \;\Rightarrow\; w_2 = 0.3 + 0.005938 = 0.3059 \] \[ \Delta b = \eta \times 1 \times \delta = 0.005938 \;\Rightarrow\; b = 0.1 + 0.005938 = 0.1059 \]

The output 0.711 was below the target 1, so \(\delta\) is positive and every weight goes up.

Pattern 2 — \((I_1 = 0,\ I_2 = 0,\ d = 0)\)

Forward pass:

\[ v = 0 \times 0.5059 + 0 \times 0.3059 + 0.1059 = 0.1059 \] \[ f = \frac{1}{1 + e^{-0.1059}} = \frac{1}{1 + 0.8995} = 0.526 \]

Backpropagation:

\[ \delta = f(1-f)(d-f) = 0.526\,(1 - 0.526)\,(0 - 0.526) = -0.1311 \] \[ \Delta w_1 = 0.1 \times 0 \times (-0.1311) = 0 \;\Rightarrow\; w_1 = 0.5059 \] \[ \Delta w_2 = 0.1 \times 0 \times (-0.1311) = 0 \;\Rightarrow\; w_2 = 0.3059 \] \[ \Delta b = 0.1 \times 1 \times (-0.1311) = -0.01311 \;\Rightarrow\; b = 0.1059 - 0.01311 = 0.09279 \]

Why only the bias moved. Each weight update is proportional to its input, \(\Delta w_i = \eta\, I_i\, \delta\). Both inputs were 0, so the weights cannot be blamed for the error and stay put; only the bias, whose "input" is always 1, absorbs the correction. Here the output 0.526 was above the target 0, so \(\delta\) is negative and the bias goes down.

Testing — input \((0, 1)\)

\[ v = 0 \times 0.5059 + 1 \times 0.3059 + 0.09279 = 0.39869 \] \[ f = \frac{1}{1 + e^{-0.39869}} = \frac{1}{1 + 0.67} = \frac{1}{1.67} = \mathbf{0.598} \]

The notes round to four decimals as they go. Carried at full precision the updates differ only in the fourth decimal — \(\delta_1 = 0.05940\), final \(b = 0.09282\) — and the test output is still 0.598.

Is 0.598 the "right" answer? It is the network's output — but no correct label for \((0, 1)\) is implied by the training data. The two rows \((1,1) \to 1\) and \((0,0) \to 0\) are consistent with both AND (which gives 0) and OR (which gives 1). This is exactly an open test: an input the network never saw, so its answer reflects what it generalised. After a single pass, 0.598 is barely above 0.5 — the network is still close to undecided.

A terminology note. The classic perceptron uses a hard threshold and the update \(\Delta w = \eta\,(d - y)\,I\). These notes use a sigmoid neuron trained with \(\delta = f(1-f)(d-f)\) — the gradient-descent delta rule that backpropagation is built on. The structure of the calculation is the same; the extra \(f(1-f)\) factor is the sigmoid's slope.

Exam Checklist

  • Compute the induced local field \(v = \sum I_i w_i + b\) first, watching the signs of the weights.
  • Know the four activation functions, their formulas and ranges, and evaluate each at a given \(v\). For the piecewise-linear one, check which piece applies first.
  • Sigmoid: \(\varphi(0) = \tfrac12\); larger slope \(a\) means a steeper curve.
  • Stochastic neuron: \(P(v) = 1/(1 + e^{-v/T})\). As \(T \rightarrow 0\) it becomes deterministic; as \(T \rightarrow \infty\), \(P \rightarrow \tfrac12\).
  • Perceptron training, per pattern: forward pass → \(\delta = f(1-f)(d-f)\) → \(\Delta w_i = \eta I_i \delta\), \(\Delta b = \eta \delta\) → new weights. Then test with the final weights.
  • A zero input leaves its weight unchanged; the sign of \(\delta\) tells you whether weights rise or fall.
