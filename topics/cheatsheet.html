1Agents & Environments

  • Agent: perceives its environment through sensors, acts on it through actuators.
  • Percept: input at one instant. Percept sequence: complete history of percepts.
  • Agent function maps percept sequences to actions: \(f: \mathcal{P}^* \rightarrow \mathcal{A}\).
  • Rational agent: for each percept sequence, selects the action expected to maximize its performance measure, given the percepts and built-in knowledge.
  • Rationality depends on 4 things: performance measure · prior knowledge · available actions · percept sequence to date.

Environment properties

  • Fully vs partially observable (unobservable = no sensors).
  • Single vs multi-agent — competitive (chess) or cooperative / partially competitive (automated car).
  • Deterministic (next state fixed by state + action) vs stochastic.
  • Episodic (action doesn't affect future) vs sequential.
  • Static vs dynamic; semi-dynamic = environment fixed but score changes with time (chess with a clock).
  • Discrete vs continuous; known vs unknown (rules, not observability).

2Uninformed Search

  • Search problem: state space · successor function (actions, costs) · start state · goal test. Solution = action sequence (plan) from start to goal.
  • State space graph: each state once. Search tree: nodes are plans (paths); can be infinite with cycles.
  • Fringe = generated, not yet expanded. Algorithms differ only in which fringe node they expand next.
  • Judge by: complete, optimal, time, space.

b = branching factor, m = max depth, s = shallowest solution depth, ℓ = depth limit, C* = optimal cost, ε = min arc cost.

Alg.FringeCompleteOptimalTimeSpace
DFSLIFO stackonly if cycles preventedNo\(b^m\)\(bm\)
BFSFIFO queueYesif costs all 1\(b^s\)\(b^s\)
DLSstack, limit ℓNo (ℓ < s)No\(b^\ell\)\(b\ell\)
IDSDLS, ℓ = 0,1,2…Yesif costs all 1\(b^s\)\(bs\)
UCSpriority queue by g(n)YesYes\(b^{C^*/\epsilon}\)\(b^{C^*/\epsilon}\)
  • IDS: DFS's memory + BFS's completeness. Overhead small — b = 10, s = 5: 123,456 vs 111,111 nodes (≈ 11%).
  • BFS better: shortest path, shallow/wide space, solution near root. DFS better: deep/narrow space, little memory, any solution will do.
  • UCS = cheapest g(n) first; explores cost contours in every direction (no goal information).

3Informed Search & Heuristics

Heuristic h(n): estimate of distance to a goal, designed per problem (Manhattan, Euclidean, straight-line distance).

AlgorithmOrders fringe by
UCSg(n) — backward cost
Greedyh(n) — forward cost; can go straight to the wrong goal
A*f(n) = g(n) + h(n)
  • A* stops when a goal is dequeued, not enqueued.
  • Admissible: \(0 \le h(n) \le h^*(n)\) (never overestimates).
  • Consistent: \(h(A) - h(C) \le \text{cost}(A \to C)\) on every arc ⇒ f never decreases along a path.
  • Consistent ⇒ admissible (not the reverse).
  • A* tree search optimal if h admissible; A* graph search optimal if h consistent.
  • h = 0 turns A* into UCS. Admissible heuristics usually come from relaxed problems.
  • Dominance: \(h_a \ge h_c\) for all n ⇒ ha expands no more nodes. max(ha, hb) of admissible heuristics is admissible.

8-puzzle

Misplaced tiles (h = 8 at start) and total Manhattan distance (h = 18) are both admissible; Manhattan dominates. At depth 12: UCS 3.6 × 10⁶ nodes, tiles 227, Manhattan 73.

Graph search

Tree search + closed set (never expand a state twice; store as a set). Keeps completeness, but with a merely admissible h it can lose optimality.

4Local Search

  • Keeps one (or k) current states, no paths ⇒ constant memory; works in huge/continuous spaces. Use when only the final state matters (8-queens).
  • Landscape: cost → find global minimum; objective → global maximum.

Hill climbing (steepest ascent)

  • Move to the best neighbour; stop when no neighbour is better. "Greedy local search".
  • Gets stuck on local maxima, ridges, plateaux (flat local max or shoulder).
  • 8-queens: 8 × 7 = 56 successors, h = attacking pairs. Solves 14% (4 steps avg); 100 sideways moves → 94%.
  • Variants: stochastic (random uphill move), first-choice (generate until better), random-restart (trivially complete).

Simulated annealing

  • Pick a random move. ΔE > 0 → always accept; otherwise accept with
\[ P = e^{\Delta E / T} \]
  • Worse moves and lower T → smaller P. Lower T slowly enough → global optimum with probability → 1. Used for VLSI layout, scheduling.

Local beam search

Keep k states; generate all successors of all k; keep the best k. Shares information between threads (not k independent restarts). Risk: lack of diversity. Stochastic beam: choose k with probability increasing with value.

Genetic algorithm

  • Population of k strings → fitness function (8-queens: non-attacking pairs, 28 = solution).
  • Selection ∝ fitness → crossover at random point → mutation with small probability.
  • Power comes from crossover combining useful blocks (schema, e.g. 246*****).

5Adversarial Search

  • Typical game: deterministic, turn-taking, two-player, zero-sum (one's gain = other's loss), perfect information.
  • Formal game: S0, PLAYER(s), ACTIONS(s), RESULT(s, a), TERMINAL-TEST(s), UTILITY(s, p).

Minimax

\[ \text{MM}(s) = \begin{cases} \text{UTILITY}(s) & \text{terminal} \\ \max_{c} \text{MM}(c) & \text{MAX} \\ \min_{c} \text{MM}(c) & \text{MIN} \end{cases} \]

c ranges over the children RESULT(s, a) of s.

Complete depth-first. Complete if tree finite; optimal vs optimal opponent. Time \(O(b^m)\), space \(O(bm)\).

Resource limits: cut off at a depth, use an evaluation function at non-terminal nodes — loses the optimality guarantee.

Alpha-beta pruning

  • α = best (highest) value for MAX so far on the path; β = best (lowest) for MIN. Start α = −∞, β = +∞.
  • MAX node: v = max(v, child); if v ≥ β prune; else α = max(α, v).
  • MIN node: v = min(v, child); if v ≤ α prune; else β = min(β, v).
  • α, β are passed down; values are returned up.
  • Same root decision as minimax; inner values may only be bounds.
  • Worst ordering \(O(b^m)\); perfect ordering \(O(b^{m/2})\) ⇒ effective branching \(\sqrt{b}\), search twice as deep.

Example leaves 4 6 7 9 1 2 0 1: left MIN → β = 6; 7 ≥ 6 prunes 9; root α = 6; right gets 2 ≤ 6 so 0, 1 pruned. Root = 6.

6Constraint Satisfaction Problems

  • Variables Xi, domains D, constraints on allowed combinations. Solution = complete assignment satisfying all constraints. For identification (goal matters, not path).
  • Map colouring: WA, NT, Q, NSW, V, SA, T; D = {R, G, B}; adjacent ≠.
  • N-queens: Qk = row of queen in column k; \(Q_i \ne Q_j\), \(|Q_i - Q_j| \ne |i - j|\).
  • Constraints: unary (1 var) · binary (2) · higher-order (3+, cryptarithmetic) · soft (preferences, costs).
  • Finite domains: \(O(d^n)\) complete assignments. Constraint graph: nodes = variables, arcs = constraints.

Backtracking search

= DFS + one variable at a time (fixed order) + check constraints as you go (fail on violation). Plain: n-queens n ≈ 25.

Improvements

  • Forward checking: after assigning, cross off conflicting values in neighbours' domains. Empty domain ⇒ backtrack now.
  • Constraint propagation: also checks unassigned–unassigned (WA = R, Q = G leaves NT = SA = {B} — FC misses it).
  • MRV (variable order): fewest legal values left — "most constrained", fail-fast.
  • LCV (value order): value ruling out the fewest values in neighbours — keep options open.
  • Structure: independent subproblems (Tasmania) solved separately.
  • MRV + LCV ⇒ 1000-queens feasible.

Paper trace: one row per step — variable assigned, then every unassigned domain with crossed-out values; mark backtracks clearly.

7Probability

  • Distribution: \(P(x) \ge 0\), \(\sum_x P(x) = 1\). Joint over n variables of domain d has \(d^n\) rows.
  • Event: sum its rows. \(P(A \cup B) = P(A) + P(B) - P(A \cap B)\).
RuleFormula
Marginal\(P(x) = \sum_y P(x, y)\)
Conditional\(P(a \mid b) = \dfrac{P(a,b)}{P(b)}\)
Product\(P(a,b) = P(a \mid b)P(b)\)
Chain\(P(x_1..x_n) = \prod_i P(x_i \mid x_1..x_{i-1})\)
Bayes\(P(a \mid b) = \dfrac{P(b \mid a)P(a)}{P(b)}\)
Independent\(P(x,y) = P(x)P(y)\) for all x, y
Cond. indep.\(P(x,y \mid z) = P(x \mid z)P(y \mid z)\)

  • Bayes' rule turns causal \(P(\text{effect} \mid \text{cause})\) into diagnostic \(P(\text{cause} \mid \text{effect})\); expand \(P(b) = \sum_a P(b \mid a)P(a)\).
  • Meningitis: \(P(+m \mid +s) \approx 0.0079\) — a tiny prior keeps the posterior small.
  • Bayes' net: DAG + a CPT per node; arcs ≈ direct influence, encode conditional independence.

7Naive Bayes

Label Y is the parent of every feature; features conditionally independent given Y.

\[ P(Y, F_1..F_n) = P(Y) \prod_i P(F_i \mid Y) \]

Parameters: \(|Y| + n\,|F|\,|Y|\) — linear in n (full joint: \(|Y|\,|F|^n\)).

Classify

  1. Count: \(P(y) = \frac{\#y}{N}\), \(P(f \mid y) = \frac{\#(f, y)}{\#y}\).
  2. Score each label: \(P(y)\prod_i P(f_i \mid y)\).
  3. Normalize: divide each score by their sum (α). Pick the largest.

Laplace smoothing (strength k)

\[ P(x) = \frac{c(x) + k}{N + k|X|} \qquad P(x \mid y) = \frac{c(x,y) + k}{c(y) + k|X|} \]
  • |X| = number of values of that variable, not rows. Denominator for a conditional uses c(y).
  • Fixes zero counts (one zero would veto a whole class). Larger k → closer to uniform.

Golf data: Sunny, Hot, Normal, No wind → Yes ≈ 0.82 (k = 0), ≈ 0.73 (k = 2).

8Machine Learning & K-Means

ML: algorithms that recognise complex patterns and make intelligent decisions based on input data. Input → learning algorithm → intelligent decision.

SupervisedUnsupervised
DataLabelled (input + output, teacher)Unlabelled (input only)
GoalInfer a functionFind hidden structure
ExamplesANN, decision tree, SVM, Bayesian net, HMMK-means, modified K-means, hierarchical, fuzzy C-means
  • Generalization: performing accurately on new, unseen examples after training.
  • Data mining: discovering unknown properties in data.
  • Close test: test with known (training) data. Open test: unseen data — measures generalization.

K-means

  1. Place k initial centroids.
  2. Assign each point to the nearest centroid: \(d = \sqrt{(x_1-x_2)^2 + (y_1-y_2)^2}\).
  3. Recompute each centroid as the mean of its points.
  4. Repeat 2–3 until the centroids stop moving.

Modified K-means changes only step 1: pick initial centroids cleverly — the two points farthest apart (distance matrix, \(n(n-1)/2\) distances). Usually fewer iterations.

Per iteration: distance table (one column per centroid) → class → new centroid as (sum/count). State ties and the stopping condition.

9Regression

Linear: \(y = a_0 + a_1x + e\)

a₀ intercept, a₁ slope, e error (residual). Build table x, y, x², xy → sums → averages.

\[ a_1 = \frac{\overline{xy} - \bar{x}\,\bar{y}}{\overline{x^2} - \bar{x}^2} \qquad a_0 = \bar{y} - a_1\bar{x} \]
  • \(\overline{x^2}\) = mean of squares ≠ \(\bar{x}^2\) = square of mean.
  • Check: line passes through \((\bar{x}, \bar{y})\).

Logistic (classification)

\[ z = \log(\text{odds}) = \ln\frac{p}{1-p} \qquad p = \frac{1}{1 + e^{-z}} \]
  • Sigmoid range (0, 1); \(s(0) = 0.5\). Classify 1 if p ≥ 0.5 ⇔ z ≥ 0 (decision boundary z = 0).
  • Target probability p → \(z = \ln\frac{p}{1-p}\) (0.9 → ln 9 = 2.197; 0.95 → ln 19 = 2.944) → solve for x.
  • Linear is wrong for pass/fail: output unbounded, not a probability.

10Fuzzy & Crisp Logic

  • Fuzzy logic: superset of Boolean logic with partial truth — degrees of membership in [0, 1]. Zadeh. Glass with 30 of 100 ml: 0.3 full, 0.7 empty.
  • Crisp set: sharp boundary. Fuzzy set: blurred boundary.
  • Core μ = 1 · support μ > 0 · boundary 0 < μ < 1.
  • Probability models ignorance ("80% chance Jane is old"); fuzzy models vagueness ("Jane is old to degree 0.8").

Operations (element by element)

Union A ∪ Bmax(μA, μB)
Intersection A ∩ Bmin(μA, μB)
Complement Ā1 − μA
Difference A − Bmin(μA, 1 − μB)

0.8/1 = element 1 with membership 0.8. Unlisted elements have μ = 0 (so they are 1 in the complement).

Membership functions

  • Triangular (a, b, c): rising \(\frac{x-a}{b-a}\), falling \(\frac{c-x}{c-b}\), else 0.
  • Trapezoidal (a, b, c, d): rising \(\frac{x-a}{b-a}\), 1 on [b, c], falling \(\frac{d-x}{d-c}\).
  • Gaussian: \(e^{-(x-c)^2/2\sigma^2}\). Singleton: 1 only at x = a.

Fuzzy inference system

  1. Fuzzification: crisp input → membership degrees.
  2. Inference: apply rules; AND = min (OR = max).
  3. Defuzzification: weighted mean of centroids \(\frac{\sum \mu_i c_i}{\sum \mu_i}\).

Why: flexible, easy to understand, tolerant of imprecise data, natural language. Uses: vehicle speed / ABS, AC & fridges, camera autofocus, washing machines, rice cookers.

Neighbouring triangles crossing: memberships sum to 1 (Cool 0.6 + Warm 0.4).

At v = 0.2: threshold 1, piecewise 0.7, sigmoid 0.5498, tanh 0.1974.

Stochastic neuron

State +1 with probability \(P(v) = \frac{1}{1 + e^{-v/T}}\), else −1. T = pseudo-temperature: T → 0 deterministic (threshold); T → ∞ gives P = ½ (pure noise).

Perceptron training (sigmoid, per pattern)

\[ \begin{gathered} \delta = f(1-f)(d-f) \\ \Delta w_i = \eta\, I_i\, \delta \qquad \Delta b = \eta\, \delta \end{gathered} \]
  • Forward pass (v, f) → δ → update every weight and the bias → next pattern → test with final weights.
  • Input 0 ⇒ that weight is unchanged. Sign of δ: f < d ⇒ weights rise.

12Markov Models

  • Markov property: \(X_t \perp X_1..X_{t-2} \mid X_{t-1}\) — future depends on the past only through the present.
  • Stationarity: \(P(X_t \mid X_{t-1})\) is the same at every t.
  • Parameters: initial \(P(X_1)\) + transition table.
\[ P(X_1..X_T) = P(X_1)\prod_{t=2}^{T} P(X_t \mid X_{t-1}) \]

Mini-forward algorithm

\[ P(x_t) = \sum_{x_{t-1}} P(x_t \mid x_{t-1})\, P(x_{t-1}) \]

Stationary distribution

  • \(P_\infty(x) = \sum_{x'} P(x \mid x')\, P_\infty(x')\) — one more step leaves it unchanged; independent of the start.
  • Write one balance equation per state, keep n − 1, add \(\sum P_\infty = 1\), solve.
  • Matrix: row = from, column = to; rows sum to 1. Use column x for \(P_\infty(x)\).

Weather (sun→sun 0.9, rain→sun 0.3): \(P_\infty\) = ⟨0.75, 0.25⟩.

13Monte Carlo Methods

Repeated random sampling to estimate a quantity — heuristic, not exact.

Expected value\(\hat{\mu} = \frac{1}{N}\sum X_i\)
Probability\(\hat{P}(A) = \frac{1}{N}\sum I_i\) (indicator)
Why it worksLaw of large numbers: \(\hat{\mu} \to \mu\)
Error\(SE = \sigma/\sqrt{N}\) — 100× runs ⇒ 10× less error
π\(\hat{\pi} = 4N_c/N\), inside if \(x^2 + y^2 \le 1\)
Action value\(\hat{Q}(s,a) = \frac{G_1 + .. + G_N}{N}\)
MCTS\(Q(s,a) = W(s,a)/N(s,a)\)

Steps: define problem → model inputs → run simulations → analyse the distribution of results.

Simulation problems (e.g. clinic queue)

  1. Cumulative probabilities → random-number intervals (0.30 → 00–29, next 0.15 → 30–44 …).
  2. Map each random number to a category / service time.
  3. Event table: start = max(arrival, server free); wait = start − arrival; idle = gaps.
  4. Average waiting time = total wait / n.

14First-Order Logic

FOL / predicate logic: knowledge representation of objects, properties, relationships and rules, so AI can reason from known facts.

  • Constants (John) · variables (x) · predicates — true/false (Brother(John, Bob)) · functions — return an object (FatherOf(John)) · quantifiers ∀ ∃ · connectives ∧ ∨ → ↔ ¬.
  • P → Q is false only when P true, Q false.
EnglishFOL
All P are Q∀x (P(x) → Q(x))
Some P is Q∃x (P(x) ∧ Q(x))
No P is Q∀x (P(x) → ¬Q(x))
Every P has some R∀x (P(x) → ∃y R(x,y))

Universal instantiation + modus ponens

Rule: ∀x (Human(x) → Mortal(x))
Fact: Human(Socrates)
UI, x = Socrates: Human(Socrates) → Mortal(Socrates)
MP: ∴ Mortal(Socrates)

  • With ∧ in the if-part, show every condition true first.
  • Only forwards: Mortal(Tom) does not give Human(Tom).
  • ∀x∃y ≠ ∃y∀x. State argument order, e.g. Father(y, x): y is father of x.

Applications: knowledge representation, theorem proving, NLP, expert systems, semantic web.
