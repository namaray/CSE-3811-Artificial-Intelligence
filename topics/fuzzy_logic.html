Fuzzy & Crisp Logic

Partial truth, membership functions, fuzzy set operations and fuzzy inference

Brief History

  • Aristotle — classical logic. The Law of Bivalence: every proposition is either True or False, with no middle.
  • Jan Łukasiewicz proposed a three-valued logic: True, False and Possible.
  • Lotfi Zadeh finally published his paper on fuzzy logic — a part of set theory that operates over the whole range [0.0, 1.0].

What is Fuzzy Logic?

  • Fuzzy logic is a superset of Boolean (conventional) logic that handles the concept of partial truth — truth values between "completely true" and "completely false". Boolean (crisp) logic sits inside it as the special case where only 0 and 1 are allowed.
  • Fuzzy logic is multivalued. It deals with degrees of membership and degrees of truth.
  • It uses the continuum of logical values between 0 (completely false) and 1 (completely true).

Example: the glass of water

A 100 ml glass contains 30 ml of water. Consider the two concepts Empty and Full.

  • Boolean logic must give one of two answers — the glass is either full or empty.
  • Fuzzy logic can say the glass is 0.7 empty and 0.3 full, matching 30 ml out of 100.

A crisp set has a sharp boundary; a fuzzy set has a blurred one, and elements near the edge belong to it only partly.

Membership Functions

A membership function \(\mu(x)\) is a mathematical function that defines the degree of an element's membership in a fuzzy set. For a trapezoid-shaped membership function, three regions have names:

RegionMeaningCondition
CoreFull membership in A′\(\mu(x) = 1\)
SupportNon-zero membership in A′\(\mu(x) > 0\)
BoundaryPartial membership in A′\(0 < \mu(x) < 1\)

So the support contains the core, and the boundary is the support minus the core.

Example: the adult membership function

\[ \text{adult}(x) = \begin{cases} 0, & \text{age}(x) < 16 \\[4pt] \dfrac{\text{age}(x) - 16}{4}, & 16 \le \text{age}(x) \le 20 \\[8pt] 1, & \text{age}(x) > 20 \end{cases} \]

Membership rises linearly from 0 at 16 years to 1 at 20 years. So adult(17) = 0.25, adult(18) = 0.5 and adult(19) = 0.75.

Careful — two slides disagree. The age table above gives Jenny (18) a fuzzy membership of 0.75, but this function gives an 18-year-old 0.5; it only reaches 0.75 at age 19. The table slide never states which function it uses, so they may simply be different curves. In an exam, compute from whatever function the question gives you, rather than recalling 0.75 for Jenny.

Fuzzy Logic vs. Probability

Both use numbers from 0 to 1, with 0.0 meaning false (or non-membership) and 1.0 meaning true, so at first glance they look alike. They answer different questions:

ProbabilityFuzzy logic
Statement"There is an 80% chance that Jane is old.""Jane's degree of membership in the set of old people is 0.80."
ModelsIgnorance — Jane either is or is not old; we just don't know which.Vagueness — "old" itself has no sharp boundary, and Jane is old to a degree.

Learning Jane's exact age would resolve the probability, but it would not change the fuzzy membership — she would still be "old to degree 0.80".

Why Use Fuzzy Logic?

  • Fuzzy logic is flexible.
  • It is conceptually easy to understand.
  • It is tolerant of imprecise data.
  • It is based on natural language — rules read like "if it's sunny and warm, drive fast".

Crisp and Fuzzy Set Operations

Crisp vs. fuzzy "8"

Crisp 8 — pixel / region\(\mu\)Fuzzy 8 — pixel / region\(\mu\)
Inside the 81Centre of 81.0
Outside the 80Edge of 80.6 – 0.8
Near boundary0.3 – 0.5
Far outside0.0 – 0.1

In crisp logic a pixel either belongs to the set (1) or does not (0). In fuzzy logic it belongs to a degree between 0 and 1 — a blurred digit is still recognisably an 8.

The four operations

OperationCrispFuzzy
Union — disjunction\(A \cup B\): all elements in A or B\(\mu_{A \cup B}(x) = \max(\mu_A(x), \mu_B(x))\)
Intersection — conjunction\(A \cap B\): common elements\(\mu_{A \cap B}(x) = \min(\mu_A(x), \mu_B(x))\)
Complement\(\bar{A}\): not in A\(\mu_{\bar{A}}(x) = 1 - \mu_A(x)\)
Difference\(A - B\): in A but not in B\(\mu_{A-B}(x) = \min(\mu_A(x),\ 1 - \mu_B(x))\)

Difference is just intersection with a complement, \(A - B = A \cap \bar{B}\), which is why its formula combines min with \(1 - \mu_B\). With memberships restricted to 0 and 1, all four fuzzy formulas reduce exactly to the crisp operations — fuzzy logic genuinely generalises Boolean logic.

Worked example

Over the universe \(\{1, 2, 3, 4, 5\}\), take

\[ A = \{1/2 + 0.5/3 + 0.3/4 + 0.2/5\} \qquad B = \{0.5/2 + 0.7/3 + 0.2/4 + 0.4/5\} \]

Reading the notation. Each term is membership / element, so \(0.5/3\) means "element 3 with membership 0.5". It is not a fraction, and the + signs are not addition — they just list the members. Any element not listed has membership 0, which is why element 1 has \(\mu_A(1) = 0\).

Fuzzification Methods

Fuzzification converts a crisp input value into a degree of membership in a fuzzy set, using a membership function. The common shapes:

ShapeMembership functionExample
Singleton (crisp) \(\mu_A(x) = \begin{cases} 1, & x = a \\ 0, & x \neq a \end{cases}\) \(a = 30\): only 30 has membership 1
Gaussian \(\mu_A(x) = \exp\!\left(-\dfrac{(x-c)^2}{2\sigma^2}\right)\) \(c = 30,\ \sigma = 5\): smooth bell curve
Triangular \(\mu_A(x) = \begin{cases} \frac{x-a}{b-a}, & a \le x \le b \\ \frac{c-x}{c-b}, & b \le x \le c \\ 0, & \text{otherwise} \end{cases}\) \(a = 10,\ b = 20,\ c = 30\): rises then falls
Trapezoidal \(\mu_A(x) = \begin{cases} \frac{x-a}{b-a}, & a \le x \le b \\ 1, & b \le x \le c \\ \frac{d-x}{d-c}, & c \le x \le d \\ 0, & \text{otherwise} \end{cases}\) \(a = 10,\ b = 20,\ c = 30,\ d = 40\): flat top

Try it. Using each example's parameters:

ShapeInputWorking\(\mu\)
Triangular\(x = 25\)falling side: \(\frac{30-25}{30-20}\)0.5

The first step is always the same: decide which piece of the function the input falls in, then use that piece's formula.

Fuzzy Inference: How Fast Should I Drive?

Question: how fast will I go if it is 65 °F with 25% cloud cover?

A fuzzy controller works in three stages:

  1. Fuzzification — turn the measured numbers into linguistic values, i.e. membership degrees.
  2. Fuzzy inference — apply the rules to those degrees to get degrees for the command values.
  3. Defuzzification — turn the command values back into a single number to act on.

Stages 1 and 3 cross between the numerical level and the linguistic level; stage 2 happens entirely in words.

Inputs and outputs

Input — Temp: {Freezing, Cool, Warm, Hot}, as in the chart above.

Input — Cover: {Sunny, Partly cloudy, Overcast}

Output — Speed: {Slow, Fast}

Rules

  • If it's Sunny and Warm, drive Fast.
  • If it's Cloudy and Cool, drive Slow.
\[ \text{Sunny(Cover)} \wedge \text{Warm(Temp)} \Rightarrow \text{Fast(Speed)} \] \[ \text{Cloudy(Cover)} \wedge \text{Cool(Temp)} \Rightarrow \text{Slow(Speed)} \]

"Cloudy" in the rule refers to the Partly cloudy set. The driving speed is the combination of the outputs of both rules.

Step 1 — Fuzzification

The slides read the input membership levels off the graphs as:

\[ 65\,°\text{F} \;\Rightarrow\; \text{Cool} = 0.4,\quad \text{Warm} = 0.7 \] \[ 25\%\ \text{cover} \;\Rightarrow\; \text{Sunny} = 0.8,\quad \text{Cloudy} = 0.2 \]

Step 2 — Inference

A fuzzy AND (\(\wedge\)) is the min of its inputs — the intersection operation from earlier. Each rule's strength becomes the degree of its conclusion:

\[ \text{Fast} = \text{Sunny} \wedge \text{Warm} = \min(0.8,\ 0.7) = \mathbf{0.7} \] \[ \text{Slow} = \text{Cloudy} \wedge \text{Cool} = \min(0.2,\ 0.4) = \mathbf{0.2} \]

Step 3 — Defuzzification

The speed is now 20% Slow and 70% Fast. To turn that into one number, take each output set's centroid — here, the location where its membership reaches 100%: Slow at 25 mph and Fast at 75 mph. Then take the weighted mean, weighting each by its rule strength:

\[ \text{Speed} = \frac{0.2 \times 25 + 0.7 \times 75}{0.2 + 0.7} = \frac{5 + 52.5}{0.9} = \frac{57.5}{0.9} \approx \mathbf{63.9\ \text{mph}} \]

The slides write this as \((2 \times 25 + 7 \times 75)/9 = 63.8\) mph — the same calculation with everything scaled by 10. The exact value is 63.89, which rounds to 63.9; 63.8 is a truncation.

The slide's membership values don't match its own graphs. Read the drawn functions exactly and 65 °F is on Cool's falling side and Warm's rising side:

\[ \text{Cool}(65) = \frac{70-65}{70-50} = 0.25 \qquad \text{Warm}(65) = \frac{65-50}{70-50} = 0.75 \] \[ \text{Sunny}(25) = \frac{40-25}{40-20} = 0.75 \qquad \text{Cloudy}(25) = \frac{25-20}{50-20} \approx 0.167 \]

A tell-tale sign: where two neighbouring triangles cross like this, the memberships sum to exactly 1 (0.25 + 0.75). The slide's 0.4 + 0.7 = 1.1 is impossible for these curves — those values were read approximately off the graph.

Carrying the exact values through:

\[ \text{Fast} = \min(0.75,\ 0.75) = 0.75 \qquad \text{Slow} = \min(0.167,\ 0.25) = 0.167 \] \[ \text{Speed} = \frac{0.167 \times 25 + 0.75 \times 75}{0.167 + 0.75} \approx \mathbf{65.9\ \text{mph}} \]

In an exam: if the question gives you membership values, use them exactly as given — the answer will be marked against them. If it gives you the functions, compute the values from the functions. Expect 63.8 / 63.9 mph if you are given this slide's example as stated.

Applications

  • Automobile and other vehicle subsystems — speed control, anti-lock braking systems.
  • Temperature controllers — air conditioners, refrigerators.
  • Cameras — auto-focus.
  • Home appliances — rice cookers, dishwashers, washing machines and others.

Conclusion

  • Fuzzy logic provides a way to calculate with imprecision and vagueness.
  • It can be used to represent some kinds of human expertise.
  • The control stability, reliability, efficiency and durability of fuzzy logic make it popular.
  • The speed and complexity of application production would not be possible without systems like fuzzy logic.

Exam Checklist

  • Contrast crisp and fuzzy sets: sharp vs. blurred boundary, and full / partial / non-membership.
  • Define core (\(\mu = 1\)), support (\(\mu > 0\)) and boundary (\(0 < \mu < 1\)).
  • Explain fuzzy logic vs. probability: vagueness vs. ignorance.
  • Apply the operations element by element: union = max, intersection = min, complement = 1 − μ, difference = min(μA, 1 − μB).
  • Read the \(\mu/x\) notation correctly, and include every element of the universe in a complement.
  • Evaluate triangular, trapezoidal and Gaussian membership functions — find the right piece first.
  • Run the three-stage pipeline: fuzzification → inference (AND = min) → defuzzification (weighted mean).
