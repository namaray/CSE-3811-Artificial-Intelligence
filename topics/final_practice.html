Constraint Satisfaction Problems

Convention used in every CSP answer (the same one as the sheet's own sample solution): forward checking after each assignment; MRV picks the variable with the fewest remaining values; a tie is broken by the degree heuristic (most constraints on unassigned variables); LCV picks the value that rules out the fewest values in neighbouring domains; a remaining tie takes the first option (Red, Green, Blue order), unless the question gives its own tie rule.

Q8. Chess pieces CPT

Solution

a) Values of a and b

Each conditional distribution P(C | A = age) must sum to 1 over its values:

\[ \begin{aligned} \text{Young: } & a + 3a = 1 \Rightarrow 4a = 1 \Rightarrow a = \tfrac14 = 0.25 \\ \text{Senior: } & 2b + 3b = 1 \Rightarrow 5b = 1 \Rightarrow b = \tfrac15 = 0.2 \end{aligned} \]

b) Young players who like the Knight

\[ P(\text{Knight} \mid \text{Young}) = 3a = 3 \times 0.25 = 0.75 = 75\% \]

That is 0.75 × 40 = 30 of the 40 young players.

a = 0.25, b = 0.2  ·  75% of young players like the Knight

✓ A CPT row group sums to 1 for each value of the parent — not across the whole table. If a question instead asked for P(Young, Knight) out of all 100 players, it would be 0.4 × 0.75 = 0.3.

Q9. Meningitis and stiff neck

Solution

Given: \(P(+s \mid +m) = 0.5\), \(P(+m) = 0.0001\), so \(P(-m) = 0.9999\), and \(P(+s \mid -m) = 0.05\).

\[ \begin{aligned} P(+m \mid +s) &= \frac{P(+s \mid +m)\,P(+m)}{P(+s \mid +m)P(+m) + P(+s \mid -m)P(-m)} \\[4pt] &= \frac{0.5 \times 0.0001}{0.5 \times 0.0001 + 0.05 \times 0.9999} = \frac{0.00005}{0.050045} \approx 0.000999 \end{aligned} \]
P(meningitis | stiff neck) ≈ 0.001 (about 0.1%)

✓ The posterior stays tiny because the prior is tiny — 1 in 10,000 — even though meningitis causes stiff neck half the time.

Q12. Rain, sprinkler, wet grass

Solution

Structure: A → B, and A, B → C, so

\[ P(A,B,C) = P(A)\,P(B \mid A)\,P(C \mid A,B) \]

(i) P(A = T, B = T, C = T)

\[ P(+a,+b,+c) = P(+a)\,P(+b \mid +a)\,P(+c \mid +a,+b) = 0.3 \times 0.4 \times 0.9 = 0.108 \]

(ii) P(A = T | C = T) with Bayes' rule

\[ P(+a \mid +c) = \frac{P(+c \mid +a)\,P(+a)}{P(+c)} \]

Sum out B to get \(P(+c \mid a)\):

\[ \begin{aligned} P(+c \mid +a) &= P(+b \mid +a)P(+c \mid +a,+b) + P(-b \mid +a)P(+c \mid +a,-b) \\ &= 0.4(0.9) + 0.6(0.8) = 0.84 \\[4pt] P(+c \mid -a) &= P(+b \mid -a)P(+c \mid -a,+b) + P(-b \mid -a)P(+c \mid -a,-b) \\ &= 0.6(0.7) + 0.4(0.1) = 0.46 \\[4pt] P(+c) &= P(+c \mid +a)P(+a) + P(+c \mid -a)P(-a) \\ &= 0.84(0.3) + 0.46(0.7) = 0.252 + 0.322 = 0.574 \end{aligned} \]
\[ P(+a \mid +c) = \frac{0.84 \times 0.3}{0.574} = \frac{0.252}{0.574} \approx 0.439 \]
(i) 0.108  ·  (ii) P(Rain | Wet grass) ≈ 0.439

b) Why Laplacian smoothing?

  • If a feature value never occurs with a class in the training data, its estimate \(P(x \mid y) = 0\).
  • Naive Bayes multiplies the likelihoods, so that single zero makes the whole class score 0 — one unseen word vetoes the class no matter how strongly every other word supports it (overfitting to the training data).
  • Laplace smoothing adds k to every count: \(P(x \mid y) = \frac{c(x,y) + k}{c(y) + k|X|}\), so no probability is ever exactly 0 and the estimates are pulled slightly toward uniform.
