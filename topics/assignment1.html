(b) An optimizer suggests the following model for the odds of a student passing an exam:

\[ \log(\text{odds}) = z = -20 + 0.8 \times \text{hours} \]

(b) 1. Calculate the probability of passing for a student who studies 28 hours. [2 marks]

Answer

Sigmoid: \(p = \dfrac{1}{1 + e^{-z}}\)

\[ \begin{aligned} z &= -20 + 0.8 \times 28 = -20 + 22.4 = 2.4 \\ p &= \frac{1}{1 + e^{-2.4}} = \frac{1}{1 + 0.0907} = \frac{1}{1.0907} = 0.917 \end{aligned} \]
∴ P(pass) ≈ 0.917, i.e. about 91.7 %

(b) 2. Find the minimum number of study hours needed to pass with a probability of more than 90%. [3 marks]

Answer

Set \(p = 0.90\), solve for \(z\), then solve the model for hours.

\[ \begin{aligned} \frac{1}{1 + e^{-z}} &= 0.90 \\ 0.90\,(1 + e^{-z}) &= 1 \\ 0.90\,e^{-z} &= 0.10 \\ e^{-z} &= \frac{0.10}{0.90} = 0.1111 \\ -z &= \ln(0.1111) = -2.197 \\ z &= 2.197 \end{aligned} \]
\[ \begin{aligned} 2.197 &= -20 + 0.8 \times \text{hours} \\ 0.8 \times \text{hours} &= 22.197 \\ \text{hours} &= \frac{22.197}{0.8} = 27.75 \end{aligned} \]
∴ The student must study more than 27.75 hours (≈ 28 hours) to pass with probability above 90 %

✓ Check: part 1 showed 28 hours gives 91.7 % > 90 %. Shortcut: \(z = \ln\frac{p}{1-p} = \ln\frac{0.9}{0.1} = \ln 9 = 2.197\).

Answer

Regression is a supervised learning technique that models the relationship between input (independent) variable(s) and an output (dependent) variable, so that the output can be predicted for new inputs.

2. In the equation \(y = a_0 + a_1x + e\), explain what \(a_0\), \(a_1\) and \(e\) each represent. [2 marks]

Answer
  • \(a_0\) (intercept): the value of \(y\) when \(x = 0\) — where the line cuts the y-axis.
  • \(a_1\) (slope / regression coefficient): the change in \(y\) for a one-unit increase in \(x\).
  • \(e\) (error / residual): the difference between the actual \(y\) and the predicted \(y\) — the part the line cannot explain.

3. Write the sigmoid function and sketch its S-curve. State its range and explain the role of the 0.5 threshold value in classification. [3 marks]

Answer
\[ s(z) = \frac{1}{1 + e^{-z}} \]
  • Range: \(0 < s(z) < 1\) — \(s(z) \to 0\) as \(z \to -\infty\), \(s(0) = 0.5\), \(s(z) \to 1\) as \(z \to +\infty\).
  • Role of the 0.5 threshold: if \(p \ge 0.5\) the input is classified as class 1 (e.g. pass); if \(p < 0.5\) as class 0 (fail). \(p = 0.5\) exactly when \(z = 0\), so \(z = 0\) is the decision boundary.

4. Why is linear regression not suitable for a pass/fail prediction problem, while logistic regression is? [2 marks]

Answer
  • Linear regression gives an unbounded output (it can be below 0 or above 1), so it cannot be read as a probability; a straight line also fits 0/1 data poorly.
  • Logistic regression passes the linear part through the sigmoid, which squeezes the output into (0, 1) — a valid probability — and the 0.5 threshold then gives a clear pass / fail class.

5. State the four steps of the k-means clustering algorithm. How does the modified k-means algorithm differ from it? [1 mark]

Answer
  1. Place k points in the space as the initial group centroids.
  2. Assign each object to the group with the closest centroid.
  3. When all objects are assigned, recalculate the k centroids (mean of each group).
  4. Repeat steps 2–3 until the centroids no longer move.

Modified k-means changes only step 1: the initial centroids are selected cleverly — e.g. the two points farthest apart — instead of arbitrarily.

Q6. Fuzzy Logic Concepts

1. What is fuzzy logic? Differentiate between crisp (Boolean) logic and fuzzy logic using the example of a 100 ml glass containing 30 ml of water. [2 marks]

Answer

Fuzzy logic is a superset of Boolean (crisp) logic that handles partial truth — truth values anywhere between 0 (completely false) and 1 (completely true). It deals with degrees of membership and degrees of truth.

  • Crisp logic: only two answers are allowed — the glass is either Full (1) or Empty (0).
  • Fuzzy logic: the glass is 0.3 full and 0.7 empty (30 ml out of 100 ml).

2. With a neat diagram of a trapezoidal membership function, define its core, support and boundary regions. [2 marks]

Answer
  • Core: region of full membership, \(\mu(x) = 1\) (from b to c).
  • Support: region of non-zero membership, \(\mu(x) > 0\) (from a to d).
  • Boundary: region of partial membership, \(0 < \mu(x) < 1\) (a to b, and c to d).

3. Explain the difference between fuzzy logic and probability. Illustrate with the statement about a person being “old” with a value of 0.8. [2 marks]

Answer
ProbabilityFuzzy logic
Statement“There is an 80% chance that the person is old.”“The person’s degree of membership in the set of old people is 0.8.”
ModelsIgnorance / uncertainty — the person either is or is not old; we just do not know whichVagueness — “old” has no sharp boundary; the person is old to a degree of 0.8

Both use numbers from 0 to 1, but probability answers “how likely?” while fuzzy logic answers “to what degree?”.

4. Draw and explain the three stages of a fuzzy inference system: fuzzification, fuzzy inference and defuzzification. [2 marks]

Answer
  1. Fuzzification: converts crisp numeric inputs into membership degrees (linguistic values) using membership functions — e.g. 58 °F → Cool 0.6, Warm 0.4.
  2. Fuzzy inference: applies the IF–THEN rules from the rule base to the membership degrees (AND = min) to get the strength of each output — e.g. Fast 0.25, Slow 0.5.
  3. Defuzzification: converts the fuzzy output back into one crisp number — e.g. weighted mean of centroids → 41.67 mph.
