Naive Bayes

P1. Sports or Informatics (Laplace k = 1)

Solution

Step 1 — Formulas

P(y) = ( c(y) + k ) / ( N + k·|Y| ) P(x | y) = ( c(x,y) + k ) / ( c(y) + k·|X| ) k = 1, N = 11 documents, |Y| = 2 classes, |X| = 2 (every word is Yes/No)

Step 2 — Priors

Count the labels: Sports = 6, Informatics = 5.

P(Sports) = (6 + 1) / (11 + 1×2) = 7/13 P(Info) = (5 + 1) / (11 + 1×2) = 6/13

Step 3 — Likelihoods

Count each query value inside each class. Denominators: Sports 6 + 2 = 8, Informatics 5 + 2 = 7.

Word = valueSports: count → (c+1)/8Informatics: count → (c+1)/7
goal = Yes3 → 4/81 → 2/7
tutor = No5 → 6/82 → 3/7
variance = No4 → 5/82 → 3/7
speed = Yes3 → 4/81 → 2/7
defence = No2 → 3/84 → 5/7
performance = Yes4 → 5/83 → 4/7
field = Yes4 → 5/81 → 2/7

Step 4 — Multiply prior × likelihoods

P(Sports | doc) ∝ 7/13 × 4/8 × 6/8 × 5/8 × 4/8 × 3/8 × 5/8 × 5/8 = 0.00924 P(Info | doc) ∝ 6/13 × 2/7 × 3/7 × 3/7 × 2/7 × 5/7 × 4/7 × 2/7 = 0.000807

Step 5 — Normalize

P(Sports | doc) = 0.00924 / (0.00924 + 0.000807) ≈ 0.92 P(Info | doc) = 0.000807 / (0.00924 + 0.000807) ≈ 0.08
Since 0.00924 > 0.000807, the new document is classified as Sports (≈ 92%)

✓ With k = 1 and Yes/No words: add 1 on top and 2 at the bottom of every likelihood; the prior's bottom also gets +2 because there are 2 classes.

✓ The likelihood denominator comes from the class count (6 or 5), never from N = 11.

✓ Comparing the two products already decides the class — normalize only when the question asks for the probability.
