Naive Bayes

P1. Sports or Informatics (Laplace k = 1)

Solution

Ans:

Let, c1 = Sports document c2 = Informatics document x1 = goal = Yes x5 = defence = No x2 = tutor = No x6 = performance = Yes x3 = variance = No x7 = field = Yes x4 = speed = Yes

Prior probabilities

Sports = 6 documents, Informatics = 5 documents, total = 11. Laplace smoothing with k = 1 and 2 classes adds 1 on top and 2 at the bottom:

P(c1) = (6 + 1) / (11 + 2) = 7/13 P(c2) = (5 + 1) / (11 + 2) = 6/13

Conditional probabilities

Every word has 2 values (Yes / No), so add 1 to each count and 2 to the class total: c1 gives (count + 1)/8, c2 gives (count + 1)/7.

P(x1|c1) = (3+1)/8 = 4/8 P(x1|c2) = (1+1)/7 = 2/7 P(x2|c1) = (5+1)/8 = 6/8 P(x2|c2) = (2+1)/7 = 3/7 P(x3|c1) = (4+1)/8 = 5/8 P(x3|c2) = (2+1)/7 = 3/7 P(x4|c1) = (3+1)/8 = 4/8 P(x4|c2) = (1+1)/7 = 2/7 P(x5|c1) = (2+1)/8 = 3/8 P(x5|c2) = (4+1)/7 = 5/7 P(x6|c1) = (4+1)/8 = 5/8 P(x6|c2) = (3+1)/7 = 4/7 P(x7|c1) = (4+1)/8 = 5/8 P(x7|c2) = (1+1)/7 = 2/7

Why 8 and 7? Smoothing adds k to the count of every option of the attribute, not only the one being asked about. goal can be Yes or No, so both get +1 and the class total grows by 2:

Raw Smoothed goal = Yes 3 → 3 + 1 = 4 goal = No 3 → 3 + 1 = 4 Sports total 6 → 6 + 2 = 8 (both options got +1) P(goal = Yes | Sports) = 4/8 P(goal = No | Sports) = 4/8 sum = 8/8 = 1 ✓

Informatics has 5 documents, so its bottom is 5 + 2 = 7. Using 6 + 1 = 7 instead would give 4/7 + 4/7 = 8/7 > 1, which is impossible.

Rule: +k on top, +k × (number of options) on the bottom.

  • Start from the raw class count (Sports 6, Informatics 5), not from the prior's numerator. Here 7 + 1 = 8 only by coincidence; with a 3-option attribute the bottom is 6 + 3 = 9, and with k = 2 it is 6 + 2×2 = 10.
  • Prior vs likelihood: the prior's +2 (11 + 2 = 13) counts the classes; the likelihood's +2 (6 + 2 = 8) counts the options of the word. They are both 2 here only because there are 2 classes and every word is Yes/No.
  • When k is given, smooth from the very start — priors and every conditional, for every class, even if no count is zero. Only when no k is given do you work with raw counts first and apply the "Laplacian correction" if a zero appears, as in the handwritten notes.

For c1 (Sports)

∴ P(c1|X) = P(X|c1) P(c1) / P(X) ≅ P(X|c1) P(c1) = P(x1 x2 x3 x4 x5 x6 x7 | c1) P(c1) ; [Here X = x1 x2 x3 x4 x5 x6 x7] = P(x1|c1) P(x2|c1) P(x3|c1) P(x4|c1) P(x5|c1) P(x6|c1) P(x7|c1) P(c1) = 4/8 * 6/8 * 5/8 * 4/8 * 3/8 * 5/8 * 5/8 * 7/13 = 0.00924

For c2 (Informatics)

∴ P(c2|X) = P(X|c2) P(c2) / P(X) ≅ P(X|c2) P(c2) = P(x1 x2 x3 x4 x5 x6 x7 | c2) P(c2) ; [Here X = x1 x2 x3 x4 x5 x6 x7] = P(x1|c2) P(x2|c2) P(x3|c2) P(x4|c2) P(x5|c2) P(x6|c2) P(x7|c2) P(c2) = 2/7 * 3/7 * 3/7 * 2/7 * 5/7 * 4/7 * 2/7 * 6/13 = 0.000807

Maximum probability

∴ Max{ P(ci|X) } ≅ max{ P(X|c1) P(c1) , P(X|c2) P(c2) } = max{ P(c1|X) , P(c2|X) } = max( 0.00924 , 0.000807 ) = 0.00924
∴ Prediction: The new document belongs to the Sports category.  Ans.

✓ The handwritten notes' "Laplacian correction" example (pages 9–10) only corrects the class that has a zero count, by adding one virtual record per value. This question asks for Laplace smoothing with k = 1, so every count gets +1 for both classes, as above.

✓ P(X) is the same for both classes, so it is dropped (written ≅). Compare P(X|ci)P(ci) directly.

✓ The denominator for P(x|c) is the class total + 2 (6 + 2 = 8, 5 + 2 = 7), never 11 + 2.
