Informed Search Strategies & Heuristic Functions

Classes 4-6

Search Heuristics

A heuristic is a function that estimates how close a state is to a goal. It is designed for a particular search problem.

Examples: Manhattan distance or Euclidean distance for pathing problems.

Greedy Search

Strategy: Expand the node that you think is closest to a goal state.

Heuristic is used to estimate the distance to the nearest goal for each state. A common case is that "best-first" takes you straight to the (wrong) goal. Worst-case: like a badly-guided DFS.

A* Search

A* Search combines the benefits of Uniform Cost Search (UCS) and Greedy Search.

  • UCS orders by path cost, or backward cost \( g(n) \).
  • Greedy orders by goal proximity, or forward cost \( h(n) \).
  • A* Search orders by the sum:
\[ f(n) = g(n) + h(n) \]

When should A* terminate?

We should only stop when we dequeue a goal, not when we enqueue a goal.

Is A* Optimal?

A* is optimal if the heuristic used is admissible (for tree search) or consistent (for graph search).

  • If the estimated good goal cost is greater than the actual bad goal cost, A* might find a suboptimal path.
  • We need estimates to be less than or equal to actual costs!

Admissibility and Consistency

Admissible Heuristics

A heuristic \( h \) is admissible (optimistic) if:

\[ 0 \leq h(n) \leq h^*(n) \]

where \( h^*(n) \) is the true cost to a nearest goal. Inadmissible (pessimistic) heuristics break optimality by trapping good plans on the fringe. Admissible heuristics slow down bad plans but never outweigh true costs.

Creating Admissible Heuristics

Most of the work in solving hard search problems optimally is in coming up with admissible heuristics. Often, admissible heuristics are solutions to relaxed problems, where new actions are available.

Consistency of Heuristics

Main idea: estimated heuristic costs \( \leq \) actual costs.

  • Admissibility: heuristic cost \( \leq \) actual cost to goal.
  • Consistency: heuristic "arc" cost \( \leq \) actual cost for each arc.
\[ h(A) - h(C) \leq \text{cost}(A \rightarrow C) \]

Consequences of consistency:

  • The \( f \) value along a path never decreases: \( h(A) \leq \text{cost}(A \rightarrow C) + h(C) \)
  • A* graph search is optimal.
  • Consistency implies admissibility.

Graph Search

Idea: Never expand a state twice.

Implementation:

  • Tree search + set of expanded states ("closed set").
  • Expand the search tree node-by-node, but before expanding a node, check to make sure its state has never been expanded before.
  • If not new, skip it. If new, add to closed set.
  • Important: store the closed set as a set, not a list.

Failure to detect repeated states can cause exponentially more work.
