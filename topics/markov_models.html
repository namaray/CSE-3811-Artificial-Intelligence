Markov Models

Classes 23 & 24  •  Markov chains, the mini-forward algorithm, stationary distributions

This deck covers Markov chains — the state is observed directly. It does not cover Hidden Markov Models, where the state is unobserved and only noisy evidence about it is seen.

Reasoning over Time or Space

Often we want to reason about a sequence of observations:

  • Speech recognition
  • Robot localization
  • User attention
  • Medical monitoring

The Bayes' nets so far describe a single snapshot. To handle sequences we need to introduce time (or space) into our models.

Markov Models

The value of \(X\) at a given time is called the state. A Markov model is a chain of states, each depending only on the one before:

\(X_1 \rightarrow X_2 \rightarrow X_3 \rightarrow X_4 \rightarrow \cdots\)

\[ P(X_1) \qquad\qquad P(X_t \mid X_{t-1}) \]
  • Parameters: the transition probabilities, or dynamics, \(P(X_t \mid X_{t-1})\), which specify how the state evolves over time — plus the initial state probabilities \(P(X_1)\).
  • Stationarity assumption: the transition probabilities are the same at all times.
  • This is the same as an MDP transition model, but with no choice of action.

Joint distribution of a Markov model

\[ P(X_1, X_2, X_3, X_4) = P(X_1)\,P(X_2 \mid X_1)\,P(X_3 \mid X_2)\,P(X_4 \mid X_3) \]

More generally:

\[ P(X_1, X_2, \dots, X_T) = P(X_1)\,P(X_2 \mid X_1)\,P(X_3 \mid X_2) \cdots P(X_T \mid X_{T-1}) = P(X_1) \prod_{t=2}^{T} P(X_t \mid X_{t-1}) \]

Two questions to resolve:

  1. Does this indeed define a joint distribution?
  2. Can every joint distribution be factored this way, or are we making assumptions about the joint by using this factorization?

The Chain Rule and Markov Models

From the chain rule, every joint distribution over \(X_1, X_2, X_3, X_4\) can be written as:

\[ P(X_1, X_2, X_3, X_4) = P(X_1)\,P(X_2 \mid X_1)\,P(X_3 \mid X_1, X_2)\,P(X_4 \mid X_1, X_2, X_3) \]

Assuming that

\[ X_3 \perp\!\!\!\perp X_1 \mid X_2 \qquad\text{and}\qquad X_4 \perp\!\!\!\perp X_1, X_2 \mid X_3 \]

shrinks each factor to depend only on the previous state, giving exactly the Markov factorization above. In general, from the chain rule:

\[ P(X_1, \dots, X_T) = P(X_1) \prod_{t=2}^{T} P(X_t \mid X_1, X_2, \dots, X_{t-1}) \]

and assuming, for all \(t\),

\[ X_t \perp\!\!\!\perp X_1, \dots, X_{t-2} \mid X_{t-1} \]

gives the Markov factorization \(P(X_1)\prod_{t=2}^{T} P(X_t \mid X_{t-1})\).

So, the two questions answered. (1) Yes, it defines a valid joint distribution — it is the chain rule, which always holds, with some factors simplified. (2) No, not every joint can be written this way: the simplification is only legal because we assumed the conditional independences. This is the same idea as Bayes' net semantics — a Markov model is simply a Bayes' net shaped like a chain.

What is the distribution after one step?

Sum over every way of getting to "sun", weighting each by how likely it was to be in the starting state:

\[ P(X_2 = \text{sun}) = P(X_2 = \text{sun} \mid X_1 = \text{sun})\,P(X_1 = \text{sun}) + P(X_2 = \text{sun} \mid X_1 = \text{rain})\,P(X_1 = \text{rain}) \] \[ = 0.9 \times 1.0 + 0.3 \times 0.0 = 0.9 \]

The Mini-Forward Algorithm

Applying that one-step calculation repeatedly gives the mini-forward algorithm, which pushes the whole distribution forward one step at a time:

\[ P(x_t) = \sum_{x_{t-1}} P(x_t \mid x_{t-1})\,P(x_{t-1}) \]

Stationary Distributions

For most chains:

  • The influence of the initial distribution gets less and less over time.
  • The distribution we end up in is independent of the initial distribution.

The distribution we end up with is called the stationary distribution \(P_\infty\) of the chain. It is the distribution that one more step leaves unchanged:

\[ P_\infty(X) = P_{\infty+1}(X) = \sum_x P(X \mid x)\,P_\infty(x) \]

Example 1: weather

What is \(P(X)\) at time \(t = \infty\)? Write the stationary condition for each state:

\[ P_\infty(\text{sun}) = P(\text{sun} \mid \text{sun})\,P_\infty(\text{sun}) + P(\text{sun} \mid \text{rain})\,P_\infty(\text{rain}) \] \[ P_\infty(\text{rain}) = P(\text{rain} \mid \text{sun})\,P_\infty(\text{sun}) + P(\text{rain} \mid \text{rain})\,P_\infty(\text{rain}) \]

Substitute the numbers:

\[ P_\infty(\text{sun}) = 0.9\,P_\infty(\text{sun}) + 0.3\,P_\infty(\text{rain}) \;\Rightarrow\; P_\infty(\text{sun}) = 3\,P_\infty(\text{rain}) \] \[ P_\infty(\text{rain}) = 0.1\,P_\infty(\text{sun}) + 0.7\,P_\infty(\text{rain}) \;\Rightarrow\; P_\infty(\text{rain}) = \tfrac{1}{3}\,P_\infty(\text{sun}) \]

Both equations say the same thing. Adding \(P_\infty(\text{sun}) + P_\infty(\text{rain}) = 1\) pins down the values:

\[ P_\infty(\text{sun}) = \tfrac{3}{4} \qquad\qquad P_\infty(\text{rain}) = \tfrac{1}{4} \]

That matches the 0.75 / 0.25 the mini-forward algorithm converged to.

Example 2: a three-state chain

Random variable \(X \in \{a, b, c\}\) with transition matrix

\[ \begin{array}{c|ccc} & a & b & c \\ \hline a & 2/5 & 2/5 & 1/5 \\ b & 1/5 & 3/5 & 1/5 \\ c & 1/5 & 2/5 & 2/5 \end{array} \]

Read the matrix correctly. Each row is the state you are coming from and each column the state you go to, so the entry in row \(b\), column \(a\) is \(P(a \mid b) = 1/5\). You can confirm the orientation because every row sums to 1. To find \(P_\infty(a)\) you need column \(a\): \(P(a \mid a), P(a \mid b), P(a \mid c)\).

Equation for \(a\) — column \(a\) is \(2/5, 1/5, 1/5\):

\[ P_\infty(a) = \tfrac{2}{5}P_\infty(a) + \tfrac{1}{5}P_\infty(b) + \tfrac{1}{5}P_\infty(c) \] \[ \Rightarrow 5P_\infty(a) = 2P_\infty(a) + P_\infty(b) + P_\infty(c) \;\Rightarrow\; 3P_\infty(a) - P_\infty(b) - P_\infty(c) = 0 \qquad \text{(i)} \]

Equation for \(b\) — column \(b\) is \(2/5, 3/5, 2/5\):

\[ P_\infty(b) = \tfrac{2}{5}P_\infty(a) + \tfrac{3}{5}P_\infty(b) + \tfrac{2}{5}P_\infty(c) \] \[ \Rightarrow 5P_\infty(b) = 2P_\infty(a) + 3P_\infty(b) + 2P_\infty(c) \;\Rightarrow\; P_\infty(a) - P_\infty(b) + P_\infty(c) = 0 \qquad \text{(ii)} \]

Normalisation:

\[ P_\infty(a) + P_\infty(b) + P_\infty(c) = 1 \qquad \text{(iii)} \]

Solve. From (ii), \(P_\infty(b) = P_\infty(a) + P_\infty(c)\). Substituting into (iii) gives \(2P_\infty(b) = 1\), so \(P_\infty(b) = 1/2\) and \(P_\infty(a) + P_\infty(c) = 1/2\). Then (i) becomes:

\[ 3P_\infty(a) - \tfrac12 - \left(\tfrac12 - P_\infty(a)\right) = 0 \;\Rightarrow\; 4P_\infty(a) = 1 \]

which gives:

\[ P_\infty(a) = \tfrac{1}{4} \qquad P_\infty(b) = \tfrac{1}{2} \qquad P_\infty(c) = \tfrac{1}{4} \]

Why the equation for \(c\) is never used. The balance equations for all three states are not independent — any one follows from the other two, because probability that flows out of one state must flow into the others. On their own they have infinitely many solutions: any multiple of \((1, 2, 1)\) satisfies them. That is why the normalisation equation (iii) is always needed — it picks the one multiple that sums to 1. In general, for \(n\) states use any \(n - 1\) balance equations plus normalisation.

Check your answer by pushing it through one step. For column \(a\):

\[ \tfrac14 \cdot \tfrac25 + \tfrac12 \cdot \tfrac15 + \tfrac14 \cdot \tfrac15 = \tfrac{2+2+1}{20} = \tfrac14 \;✓ \]

Exam Checklist

  • State the Markov factorization \(P(X_1)\prod_{t} P(X_t \mid X_{t-1})\), and derive it from the chain rule plus the conditional independence assumption.
  • Name the two assumptions: the Markov property and stationarity.
  • Convert between a transition table, a state diagram and a matrix — and say which way the matrix is read.
  • Run the mini-forward algorithm by hand, one step at a time: \[ P(x_t) = \sum_{x_{t-1}} P(x_t \mid x_{t-1})\,P(x_{t-1}) \]
  • Find a stationary distribution: write one balance equation per state, keep \(n-1\) of them, add \(\sum P_\infty = 1\), and solve.
  • Verify by checking that one more step leaves your answer unchanged.
