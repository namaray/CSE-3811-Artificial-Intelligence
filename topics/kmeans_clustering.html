Supervised & Unsupervised Learning, K-Means

Lecture Note 1 — Dr. Ohidujjaman Tuhin, CSE, UIU

What is Machine Learning?

Machine learning is a branch of artificial intelligence. It is a scientific discipline concerned with the design and development of algorithms that recognise complex patterns and make intelligent decisions based on input data.

Input pattern  →  Learning algorithm  →  Intelligent decision

Supervised vs. Unsupervised Learning

Supervised learningUnsupervised learning
Definition The task of inferring a function from labelled training data. The problem of trying to find hidden structure in unlabelled data.
Input data Yes Yes
Output data Yes — output data / teacher data / labelled data No — no output / no teacher / no labelled data
Examples Artificial neural network, Bayesian network, support vector machine, hidden Markov model, decision tree learning K-means clustering, modified K-means clustering, hierarchical clustering, fuzzy C-means clustering

The one-line distinction to remember: supervised learning has a teacher — every training example comes with the right answer — and unsupervised learning does not, so it can only look for structure such as clusters in the inputs themselves.

Related terms

  • Generalization — the ability of an algorithm to perform accurately on new, unseen examples after having trained on a learning data set. It is the real goal of learning: memorising the training data is easy and useless.
  • Data mining — the discovery of unknown properties in data.

Close test vs. open test

  • Close test: during the test phase, known input data and output data — data the system was trained on — are applied.
  • Open test: during the test phase, unknown input data — data the system has never seen — are applied.

Example. Train a system on two rows of the AND function, then test it:

Only an open test measures generalization. A close test just confirms the system remembered its training data.

K-Means Clustering

The algorithm

  1. Place \(k\) points into the space represented by the objects being clustered. These points are the initial group centroids.
  2. Assign each object to the group that has the closest centroid.
  3. When all objects have been assigned, recalculate the positions of the \(k\) centroids as the mean of their members.
  4. Repeat steps 2 and 3 until the centroids no longer move.

Distances are Euclidean:

\[ d\big((x_1,y_1),(x_2,y_2)\big) = \sqrt{(x_1-x_2)^2 + (y_1-y_2)^2} \]

Classifying a new point

Classify (2, 7) using the previous experiment. Compare its distance to each final centroid:

\[ d_1 = \sqrt{(2-3)^2 + (7-5)^2} = \sqrt{1+4} = \sqrt{5} = 2.236 \] \[ d_2 = \sqrt{(2-5.5)^2 + (7-7)^2} = \sqrt{12.25} = 3.5 \]

Since \(2.236 < 3.5\), the point (2, 7) belongs to Class I.

Modified K-Means

Identical to K-means except for step 1: select the initial group centroids cleverly. Steps 2–4 — assign, recompute, repeat — are unchanged.

The clever choice used in the notes: compute every pairwise distance and start from the two points that are farthest apart, so the starting centroids are already well separated.

Worked example — same five points

What the clever start bought

K-meansModified K-means

Plain K-means started with two centroids only 1.414 apart, so the first assignment was poor and needed correcting. Starting far apart got the clusters right immediately. The cost is computing the distance matrix first — \(n(n-1)/2\) distances, which grows quickly for large data sets.

Exam Checklist

  • Know the supervised / unsupervised distinction — labelled vs. unlabelled data, teacher vs. no teacher — and examples of each.
  • Define generalization, and distinguish a close test (seen data) from an open test (unseen data).
  • Write out all four K-means steps.
  • Lay each iteration out as a table: one row per point, one column per centroid distance, then the assigned class.
  • Recompute centroids as the mean of each cluster's members, showing the sum over the count.
  • State the stopping condition explicitly: the assignments, and so the centroids, did not change.
  • If a point is equidistant, say which cluster you gave it.
  • For modified K-means, show the distance matrix and name the farthest pair.
